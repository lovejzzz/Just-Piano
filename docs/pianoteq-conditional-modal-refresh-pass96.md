# 条件刷新与连续输出：pass96

本轮调查pass94的age24512/24576刷新缺口。新增直接观察渲染调度标志的六点采集模式，仍不写目标代码、数据、寄存器或PC，不注入调用，不使用Pedalboard。

## 直接记录调度决定

`PIANOTEQ_CAPTURE_DISPATCH=1`将原六点中的6e5360换成472f50，其余五点保持不变。该位置在6e4f5c更新控制并设置V+80c之后、进入4e285c渲染之前。每块读取模型输入、u=V+8cc、提交的u=V+8c8及实际释放系数，用自己的释放函数重新计算并严格比较；这些实际系数不作为自己的输入。

同时保留V+80c的原始字节、V+814的phase与V+810的factor。本模式当前明确要求flag为0/1、phase=0、factor=1，不宣称覆盖其它调度周期。未要求刷新时，额外只读采集布局、P/Q、A/B、能量和模态辅助字段，作为比较目标。

完成条件没有改成“缺少刷新也算通过”：窗口必须有从0到末尾每64采样一次的完整调度决定、完整输出，实际刷新序列必须与这些决定逐项相同。需要刷新而缺少事件，或跳过刷新而缺少状态目标，仍拒绝。旧模式保留原先每块刷新的严格条件。

## 原生分支证据

REA/Ghidra指令证据`ev_6e34629d816f84d2ecc530659c85f87f176746df32916971e841da5843284d9b`，不可变ARM64原件SHA256 `8e375ff63fcb9056ae1eadd9770d28a0a61c7d79209f52a74f027c3bc13c2094`；证据包及快照各保留358条记录。

472f40..4c用6e4f5c的返回值决定是否置V+80c。4e2b40..5c读取该字节，只有等于1且phase=0才调用863008，随后清除标志；另有布局同步及周期分支，未以一个布尔值概括所有情况。

A次进程65016正常exit0，385个窗口内决定与382次真实刷新精确对应，age24512和24576的标志为false。但age17792的一次输出复制没有采到，仅383个窗口内输出，完成断言失败，保留`complete=false`。没有从其它运行填补输出，也没有将该次改称完整通过。

B次进程67118正常exit0，取得3349个包络、3349个渲染前控制观测、3307次复制、5次初始化和10路权重。385个窗口内决定、384个完成输出、382次实际刷新、两次跳过状态全部齐全，完成断言通过，六个硬件点最终关闭。两处跳过均直接记录flag=0、phase=0、factor=1。

重放857104个float32、774个double、20个uint32，共857898项零差异，包含24576帧/512 ms对应的73728个实际三组缓冲采样、100次删模态及70个十二模态尾部组/块。两次跳过之后继续使用自己的P/Q和系数，没有以原生状态重置。原320块严格回归仍通过。

通过基准后的13项反向扰动全部拒绝：单改一个完成输出、刷新P、归一化、跳过状态Q或提交u目标，各仅一处位差；改变音高、释放形状及频率下限，或删除末尾输出/刷新、跳过决定/状态，均失败；翻转跳过标志也被一致性检查拒绝。完整性不依赖捕获文件自报`complete=true`。

## 独立递推的处理

需要刷新时继续沿用自己的能量、删模态、频率投影、位置权重、衰减归一化及A/B计算。明确跳过刷新时，仍以自己的上一块状态计算能量与删模态，保留自己的旧系数和角度，再核对原生跳过状态；不从原生P/Q或辅助字段恢复自己的轨迹。

调度决定本身仍是显式观察输入，报告保留`dispatchGateIndependentlyComputed=false`。这不等于已独立恢复所有界面控制到刷新标志的生成过程，更不等于完整物理耦合或最终立体声音色通过。

## 实际完整音频仍失败

A的原生WAV为148224帧、双声道24-bit/48kHz，完整PCM与参考有158820个不同交错采样，最大整数差19。B的原生WAV只有143360帧，参考为148224帧，格式/长度严格比较直接失败；B的PCM SHA256为`f931445d52473eefecd4e1198e70966ca0ec3f90ed734a13c0e812b84e2f7ead`。没有裁齐长度或用容差改成通过。它们都是原程序生成的实验音频，尚不是独立浏览器引擎的完整WAV。

完整模型源、控制到刷新标志的独立生成、全部预设和最终立体声链仍有缺口；本轮没有合并或部署为完整复刻。
