## 具体计算

`3e2d70` 构造接口的四个 float 向量，长度均设为 129；派生构造 `62fa40` 调用它，并安装提供 B/A/设置访问器的虚表。`77d790` 检查首张向量为 0x204 字节，再填四张表。调用位置包括 `5c39e0`。

对 i=0..127，以 float32 除法生成 `x=float32(i/127)`，所有曲线调用使用 scalar reader `019a34` 和边界模式 3。令 B 为基础模型、A 为预设：

| 接口目标 | 默认分支计算 |
| --- | --- |
| I+10（note-on） | A+d88(B+6d8(x)) |
| I+40（note-off） | A+dd8(x) |
| I+28（pedal） | v=B+728(A+e28(x)); FMA(f(f(1−v)−v), A+f20, v) |
| I+58（pitch） | A+e78(x) |

设置对象+88 非零时，note-on/note-off/pedal 的预设曲线分别可由设置+90/+e0/+130 覆盖；对应 Y 向量为空则回到预设曲线。reader 的 X/Y 分别在曲线+18/+30，不能把设置+c0/+110/+160 的非空检查误认为 X。常量曲线可以 X 为空、Y 非空，仍可覆盖。基础模型曲线保持参与，pitch 不在此覆盖分支。

第 129 项并非继续对曲线求值：note-on、note-off 使用 `min(1, f(f(t[127]+t[127])−t[126]))`；pedal、pitch 复制第 128 项。没有加入推测的下界限制。

曲线求值复用既有 `linearModelCurve`，显式要求 `linear-clamp`，保留先舍入新节点乘积再 FMA 旧节点的顺序。原 reader 仍有 log-X 与特殊模式；本实现没有假定压缩存档标志能证明这些运行属性。

## 五次历史力度核对

构造器从 NY 基础存档的 B+6d8 和当前预设 A+d88 组合生成 note-on 表。B+6d8 在低力度有非恒等分段，即使当前力度附近的曲线数学上近似恒等，按原始曲线插值仍会改变 float32 舍入。因此不能以 `float32(i/127)` 替代其运算。

新审计脚本独立前向生成管理器随机字，不使用历史报告中的 randomized/prediction 字段作输入。原始 MIDI 速度取历史已独立解析的五个 note69/velocity96 事件，显式使用 velocity/128、kind0、seed0、随机化开启、全局覆盖关闭和普通线性曲线模式；后续修形在当前预设 note69 为零。
