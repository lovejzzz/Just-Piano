# 连续释放与激励接入原始P/Q：pass91

本轮把pass90的自算源、筛选索引和映射数组送入实际初始P/Q计算。正式D采集五个声部、238个四模态组，29805项检查零差异。该结论是**原始初值**，不包含随后乘半径的Q、完整递推输出或独立WAV。

## 来源与采集点

`pianoteq_capture_release_initial_chain.py`仍使用六个固定硬件点，只把pass90映射末端9517d8换成原始初值点8634d8。其余为击键前35ef10、两路权重695108、释放系数6e5360、包络返回472fd0、复制4604d4。没有增加断点数量。

筛选的sampleRate/groupCount/splitFrequency改在两路早期权重事件读取来源：模型G+98、声部+2e90、模型G+1164。两份来源快照必须一致；阈值、bypass及alignment仍从实际声部读取。依据父准备函数7185c4..7186d0及43dcb0的指令，局部配置传给9511bc，其中采样率来自G+98，分组数由参数+40复制，分频由参数+44复制。REA完整43dcb0指令证据为ev_bcfe9c5c765c3027974063f17e96e4253830d587f8efecf5ccb940d0bc69aeb5，导出后共351条记录。

原生初始化在另一线程发生，临时G指针到该阶段已清空。不能继续沿用“激励准备和初始化必须同线程”的断言，也不能在晚阶段解引用已失效的临时指针。现在按已登记的声部地址、modal=voice+168和击键epoch绑定，两个激励仍需同线程配对；初始化首次记录另建线程归属，后续组要求线程、完整布局、控制和逐组次序一致。

## 自算链进入真实初值

`pianoteq_replay_release_initial_chain.mjs`复用连续包络→复制→旧release→重复击键→谱→支持模态/历史→主次随机桥接→后处理/合并/相位→后续初始化随机推进。以自己的合并表计算索引、布局及映射，再将自己的frequency、J、amplitude和phase传给`initialModalGroup`。

真实源频率/振幅/J、栈中原始phase、索引、布局和初值数组只用于比较。没有从原生P/Q初始化自己的状态。每个四lane组比较theta、sin/cos(theta)、sin/cos(phase)、P、Q、energy、S、K和sinInverse。完整952个P和952个Q均逐位吻合。

总计29785项float32及20个uint32随机状态检查零差异。各声部期望组数由自己的筛选布局生成（46/48/48/48/48），必须完整且有序；不能拿原生组数作为自己的运算输入。报告保留`initialPredictions`，输出自己的六张原始状态数组、控制和实际初始化组列表，供后续计算接续。组间未初始化storage间隙不属于已验证状态。

本轮没有同时观察合并末端四表：它们是自己的中间结果，通过映射及P/Q消费目标核对；不能将pass90与本轮描述为同一次同时观察了所有节点。音高、调整比例和时间步仍观察，尚未从自己的上游音高模型接入本窗口。

## 83项负对照

通过正式D基准后，83项扰动全部拒绝，覆盖原始P/Q及辅助量目标、输入振幅/相位、参数、声部归属、初始化线程/组顺序、缺组/错误首尾标记、随机来源、连续包络计数及历史继承。

- 高档Rattle源改为0，除释放与重复击键差异外，还改变183个映射振幅、183个P、183个Q和183个energy。
- merge primaryGain源扰动改变30个振幅及各30个P/Q/energy。
- phaseSpread源扰动改变181个映射phase和各181个sinPhase/cosPhase/P/Q。
- 改变音高源使181个Q发生差异，而P保持原始相位定义；调整比例源也通过J改变theta和Q。
- 单独修改一个P或Q目标，只产生一个对应差异，不传播到自己的下游计算。

## 失败采集保留

A进程32832正常exit0但同线程断言拒绝，B进程32977正常exit0但晚阶段临时模型指针失效；均不完整。C进程33869正常exit0、连续包络3351块，但第二个声部只观察到1/48组，总191/238组，pending为1；该次严格拒绝，没有补组或从其它运行拼接数据。

C曾在系统条件变量广播点与自有系数点同时停止；检查栈后仅普通Continue，未把该系统停点加入自动恢复白名单。随后普通拥有者恢复策略继续。缺组的原因尚未证明，不将其解释成已确认的线程或模型原因。

D是在C终态确认之后的新独立采集；没有通过修改C记录或放宽完整性断言得到通过。
