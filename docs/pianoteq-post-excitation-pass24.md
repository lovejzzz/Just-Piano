# 和频分量、激励能量与频率展开：pass24

本轮恢复 `6164fc` 的实际数值计算。REA/Ghidra 证据 `ev_7dca52911921c2cee24cb470c5e6375355c2a4a1d3c53035bb15096f0ef67e7f` 包含该函数、平方范数 `3d4a0c`、缩放 `2ccb98`、随机扰动 `6da4b4` 和标量插值 `1d17f8`；同时逐条核对 ARM64 指令。目标仍是原先固定 SHA-256 的 ARM64 分析副本。

## 计算与运行结果

`dsp/post-excitation.mjs` 新增以下计算：

- 原始振幅的四 lane FMA 平方累积；横向加法严格为 `(lane0+lane2)+(lane1+lane3)`，包含实际零填充。
- 按运行时行索引及配对范围生成和频分量：对应列的频率、衰减及相位分别做 float32 加法；振幅按力度、两条源振幅的乘积及频率曲线权重计算。两条源振幅先相乘，不能随意改成一串左结合乘法。
- 为新增行乘上频率相关的衰减曲线；计算权重均值及后续反馈控制。
- 以每行分量均频为中心，按力度立方及展开控制调整各频率，使用原生次序的 float32 FMA。
- 以原始激励平方范数的平方根归一化整张振幅表，包括新增行；不是用新增和频分量重新计算范数。

紧凑标量插值使用先算 `float32(1/dx)` 再乘坐标差的次序。此前其他模型曲线的直接除法实现不能无条件代替它。曲线首尾按实际 boundary mode 3 钳制；当前只接受实际观察到的无 log-X/无特殊模式、一维运行时曲线。

调试副本在 `716588`（调用前）或 `71658c`（调用后）各放一个硬件断点，分开运行。全程只读内存，程序均正常 exit 0、采集错误为空；未用 Pedalboard。

`scripts/pianoteq_replay_post_excitation.mjs` 对照四张输出表、完整头字段及两个反馈输出：A4 **622 项**、四例合计 **3612 项**，总计 **4234 项逐位一致**。A4 平方范数 `1.8875203132629395`、归一化增益 `0.36393529176712036`、展开倍数 `1.036863923072815`；首振幅由 `1.0045205354690552` 变为 `0.3655804693698883`，与实际值相同。将实际对照中最后一个相位人为改动一个 float32 单位，验证器 exit 1，恰好报告该项错误；负例保留。

力度立方的系统 double `pow` 尚未单独恢复；验证器显式传入 `Math.pow`。本批最终 float32 输出全同，不能由此外推其所有 double 返回都与系统库一致。现有标量 expf 模块用于两处指数增益，不需要查询原程序数学输出。

## 接入后续计算的范围

该步骤之后还有处理：A4 在这里是 153 分量，最终筛选前是 183 分量；后续会改变 30 个已有振幅及全部已有相位。因此没有把本步骤输出冒充最终激励表。

映射验证器增加 `--post-excitation-report`，先对照本步骤预测与后续源表共有的频率/衰减前缀，再用预测替换该前缀作为计算输入。五例均通过，A4 前缀长 153，四例分别长 467、255、135、36。剩余分量及后续振幅/相位仍来自捕获，报告明确标记。

A4 继续进入独立筛选、映射、动态 pitch、初始 P/Q、系数、状态投影与 8 块连续分组渲染：**35907 个 float32 比较全同，包含 1536 个完整分组输出样本**。这仍是内部链条比较；没有生成并验证整个独立音源的最终双声道 WAV。

## 实际音频与尚未覆盖分支

A4 四次观察运行的 48kHz/24-bit 双声道 PCM 均为既有原版基准 `1907f854d5c427908038ee9629a5c8997facbb71242e30b94874fc0553a4c9d6`。

四音序列的前、后两次观察 PCM 相同，SHA-256 为 `d200ed36a61a0eda04842ff10a9a47c5c6d739ba1bac0c592a80a189b91ecf7b`，但与 pass23 后续原版重跑的 `8c098aa4730a8fb78bac70fe0e04c7e2cdd0c49519e629a4bf40fa7fe29061c5` 不同：18443 个交错采样值相差，最大差为 1 个 24-bit 整数单位，首差在交错位置 201613。原因尚未查清。不能将这两个多音捕获称为已证明对原版无扰动；原始 WAV、命令、差分统计均保留，与 pass23 首次原版本身的微小差异共同作为未解决问题。

本批 shared+160 为零，host+2fe8 为零，随机展开 enabled 为零；非零反馈控制分支没有动态覆盖。模块拒绝非零 expression、启用随机扰动、缺少配对行等未支持配置。全部模型、全部预设和完整接触力/反馈/制音耦合仍未闭合，网页仍使用原来的独立音源。

私有证据在 `debug-pass24-post-*/`、`pass24-post-excitation-decompile.json`、`pass24-pcm-verification.json`、`pass24-range-pcm-difference.json`；商业模型表和反编译全文不提交仓库。
