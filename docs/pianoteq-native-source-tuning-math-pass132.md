# 刚度/调律的原生数学计算（pass132）

2026-10-17。无新的 Pianoteq 动态捕获或完整声音等价结果。

## double exp2 / log2

新增 `native-double-exp2.mjs` 与 `native-double-log2.mjs`。exp2 保留原生分表缩减、因子多项式、指数位拼接及次正规补偿舍入；log2 保留表缩减、FMA 因子多项式、指数分支和 1 附近的高低项补偿。没有用一般 pow(2,x) 或 log(x)/ln2 替代原指令顺序。

普通独立探针读取自己加载的系统库，无 Pianoteq 附加或代码/寄存器写入。私有 `pass132-tuning-math/extraction.json` 保存代码/表/探针源码摘要；原始系统代码不提交。exp2 的 128 对数学表位于函数+0x2d7e8，log2 的 129 对表位于 +0x1c8。

普通 C 系统 oracle、seed 132 原始 IEEE 输入对照：

| 运算 | 检查数 | 差异 | NaN 语义检查 | JS 候选位差 |
| --- | ---: | ---: | ---: | ---: |
| exp2 | 101246 | 0 | 14 | 615 |
| log2 | 82779 | 0 | 10063 | 375 |

非 NaN 逐位比较；不主张 NaN payload 或浮点异常标志一致。exp2 包含 268 个旧回放不同参数、普通音频范围、完整结果范围、IEEE 随机数、溢出/次正规及表边界；log2 包含 93 个旧回放不同参数、随机/正 IEEE、次正规、1 附近和表边界。不是全 IEEE 穷举或新音符音频覆盖。完整输入和系统结果在私有 exp2-validation / log2-validation 中。

## 接入源控制和调律

新增浏览器兼容 `native-source-math.mjs`，汇集恢复的 double exp2/log2 及已有 scalar powf/expf/log10f/log2f/exp2f。两个回放新增显式 `--native-math`；新模式直接生成返回值，报告自身计算调用与外部调用分开，不读取旧 oracle 返回值作计算输入。

| --- | --- |
| 源控制 float 比较 | 1841 项、零差异 |
| 中间刚度 double 表 | 128 项、零差异 |

上述 564 条数学调用的参数/结果字与各自历史系统数学报告完全相同，刚度表及 105 个频率预测也不变。外部程序替换为始终拒绝的可执行文件后，两条基线仍通过。

七项反向检查通过：省略新模式时两条路径均被外部拒绝器阻止；分别翻转源 G28 或最终 G78 比较目标末位，各恰一项失败且预测不变；改刚度预设源，1404 项不匹配且预测改变；改仍观察的 stretch 表 note70，一共 15 项不匹配且频率预测改变；缺调律遍历记录明确拒绝。
