候选为 pass133 已验证的自算极点/权重/幅度控制/相位表，幅度使用其自行归一化结果。目标为 pass110 C 中五次击键、每击两个模式的预加权输入。共 **2160 项比较，1620 项不同**；报告 exit1、`passed=false`、`compatible=false`、`substitutedIntoVoice=false`。原始 `pass135-source-context-audit.json` 及增加列稳定性统计后的 B 均保留。

将五次实际输入按每列 float32 字节摘要去重：

| 内容 | 主路每列不同摘要数 | 次路每列不同摘要数 |

因此预加权源在连续击键中确有状态变化，不能用固定缓存假设补齐。这里只描述变化，尚未确定其生产方程；没有把衰减比例或相位差反推成补偿算法。

原指令 `04f984` 从 G+708/G+980 选择来源并复制四数组的证据仍适用，但它是复制消费点，不解释这些缓存怎样随状态更新。下一步需要取得相同配置/运行中的缓存生产输入及更新点，不能只凭该复制函数宣称恢复了动态耦合。
