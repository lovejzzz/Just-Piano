# 次级激励追加与随机相位：pass25

本轮把 pass24 后续的幅度缩放、次级表归一化与追加、随机相位计算接通到最终筛选前的四张源表。REA/Ghidra 证据 `ev_28db1d6e32fa6a3dbc8b1bf10efdeda1ad52e0faed34b81fd7d0fdefdeaf01bc` 分析 `715f98` 与 `40c1e4`；具体 float32/FMA 次序另外逐条核对 ARM64 指令。

## 独立计算

`dsp/final-excitation.mjs` 当前实现实际观察到的 mode=2、mergeControl=0 追加路径：

1. 对主表前 `min(primaryHeader[5], secondaryRows)` 行乘上主表增益。本次 A4 为前 30 个分量，增益 `0.7943282127380371`。
2. 以次级表原始振幅的四 lane FMA 平方范数归一化次级表；目标幅度为 `float32(amplitudeGain * secondaryGain)`。次级表增益和主表增益分别使用不同控制值。
3. 把次级表的频率、衰减、归一化振幅与相位追加到主表；保留原分区边界字段，更新总行数。
4. 从指定起始行开始，以四字 xorshift128 状态产生随机相位。整数先按原指令转为 float32 固定点比例，再减 0.5；不能用低精度整数比较代替完整状态比较。

每行的第一列先消耗一次共同时间扰动随机数，再消耗一次相位扰动随机数；后续各列分别消耗相位、时间扰动两次。第一列与后续列的 FMA/加法顺序不同。即使 timeSpread=0，第一项随机数仍消耗，省略会改变后续全部相位。当前五例 phaseSpread 均为 `float32(0.2)`、timeSpread=0；非零时间扰动的结果分支尚未取得运行覆盖。

## 完整最终表接到连续渲染

映射验证器增加 `--final-excitation-report`，替换 pass24 仅用频率/衰减前缀的路径。四张最终源表先与实际筛选前表逐项核对，再全部作为计算输入。五例均通过：A4 1847 项、四例 9070 项。

A4 随后经过独立筛选、源表重排、动态 pitch、三角近似、P/Q 初值、R/A/B、7 次频率投影和 8 块连续分组渲染：**35907 个 float32 比较全同，包含 1536 个完整分组输出样本**，不以捕获状态重置。这条链不再读取最终原生源表的幅度、相位、频率或衰减作计算输入。

边界仍然明确：最初两次 `692ffc` 的激励输出、随机状态初始化及运行控制仍来自捕获；尚未恢复从全部模型/预设直接生成它们的完整路径。`finalSourceTablesCalculated` 只表示上述最终表变换已计算，不表示整个琴槌/琴弦/制音器模型已完成。网页音源仍未替换为这些研究模块。

## 真实 PCM 与异常

A4 的次级捕获、相位完成捕获及追加完成重采 v2 都正常 exit 0、错误为空，48kHz/24-bit 双声道 PCM 与原版基准完全一致：`1907f854d5c427908038ee9629a5c8997facbb71242e30b94874fc0553a4c9d6`。最终正例使用追加重采 v2。

首次 A4 追加捕获的内部表与 v2 **完全相同**，但 PCM 不同：148623 个交错采样值不同，最大差 15089 个 24-bit 整数单位，首差位置 9223。这个差异不能归类为末位舍入。原始运行已正常退出，未覆盖或删除；原因未确定。

四音序列的次级、追加、相位三次采集与 pass23 原版重跑基准分别有 7952、73、2104 个交错采样值不同，最大差均为 1 个 24-bit 整数单位。三份记录均正常退出且内部数值验证通过，但不能据此声称最终 PCM 已无扰动或完全确定。

上述异常限制最终音频结论；它们没有被内部表的逐位一致结果掩盖。完整独立双声道输出仍未验证。非零 mergeControl、其它源模式、非零 timeSpread、全部预设和完整瞬时接触/反馈/制音计算仍未闭合。
