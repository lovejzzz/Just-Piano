# pass55：尾部工作线程完整1024点正向FFT

独立实现固定1024点实数正向变换，129次变换的最终频谱与同次原生计算逐位相同。该实现还未接入网页音源，不能据此认定完整钢琴声音已复刻。

## 计算与观测边界

[核心](../dsp/real-fft-core.mjs) 使用四级radix-4，参数依次为 `(ido,l1,waOffset)=(1,64,252),(4,16,240),(16,4,192),(64,1,0)`。复用已恢复的float32与融合乘加顺序；[最终组合](../dsp/real-fft-finalize.mjs) 扩展至固定1024点计划。[入口](../dsp/real-fft-1024.mjs) 自行生成有效旋转和实数最终组合系数，不读取目标频谱或原生核心值作为输入。

[采集器](../scripts/pianoteq_capture_worker_spectra.py) 仅在既有主线程入口、512帧工作节点入口/返回和末级PCM处使用硬件断点。按主状态持有的尾部节点绑定调用，返回时读取刚写入的输入环槽。槽索引从初始写指针及调用序号推导，未按样本相似度选槽。

[重放器](../scripts/pianoteq_replay_worker_spectra.mjs) 从本次主线程九行64帧输入重新形成512帧包，核对工作入口，再自行补512个零并计算频谱。它同时自行判定静音、推进槽索引/指针和时间戳。原生环槽仅作为结果核对目标。

| 检查 | 结果 |
| --- | --- |
| 完整输入包 | 16包，73728项float32逐位同 |
| 正向FFT最终频谱 | 129次，132096项float32逐位同 |
| 有效计划系数 | 1002项float32逐位同 |
| 单位增益 | 516项float32逐位同 |
| 帧、时钟、槽指针、身份、静音等字段 | 1010项一致 |
| 合计 | 208352项一致，零差异 |

22个未使用旋转表槽在原生内存中非零，独立表将其置零；完整变换结果仍逐位一致，进一步验证这些位置不参与本计划运算。

## 未完成的两次中间值采集

首次在共享FFT入口、核心返回和最终返回放断点，54次完整变换的139242项（含零填充、核心和频谱）全部相同，但原生进程随后停止，未达到128次窗口。第二次将断点动态绑定工作线程，仍在89次后停止。两次均不计为正式通过，保留原始日志，未放宽128次要求。

成功采集采用另一组已验证的工作节点边界，正常获得16次完整工作调用和129次非静音变换；该窗口没有观测FFT核心中间值。因此最终频谱验证与失败的中间值采集分别报告。[原中间值采集器](../scripts/pianoteq_capture_fft1024.py) 和 [严格重放器](../scripts/pianoteq_replay_fft1024.mjs) 保留其128次要求。

## 实际音频与负对照

原生进程53727正常exit0。完整113152帧、48kHz、双声道24-bit PCM与既有官方基准逐字节相同，PCM SHA-256为 `1907f854d5c427908038ee9629a5c8997facbb71242e30b94874fc0553a4c9d6`。8256帧末级浮点观测重新编码与同次WAV及参考前缀一致。

WAV由原生程序生成；独立实现生成的是工作输入频谱，不能把整段原生WAV说成网页引擎输出。

八个负对照全部拒绝：频谱值、工作输入包尾和有效系数各改一ULP，槽指针与时间戳修改各恰好一个差异；错误分解因子、删除主输入和不完整窗口被结构检查拒绝。共享128点最终组合和64点静音逻辑的既有队列回归116432项仍通过，`npm test`通过。

尚未完成：1024点逆变换、512帧尾部卷积输出、同次工作结果到消费块的身份/代次绑定、完整琴槌—弦—制音毡耦合、所有模型与预设，以及网页整段声音等价性。未最终合并或更新Pages。

私有证据：`debug-pass55-worker-spectra/`、`debug-pass55-fft1024/`、`debug-pass55-fft1024-bound/` 及 `pass55-*`。目标指令和运行内存没有写入，未使用Pedalboard。
