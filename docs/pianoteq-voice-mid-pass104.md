# pass104：中间组增益到Rattle的同次计算

本机Pianoteq 9.2.5 ARM64，2026-10-16。使用独立调试副本、四个只读硬件点和普通Continue；未使用Pedalboard。

从460acc的观察输入组及控制计算终端增益，再供给30bd30的Rattle组件。460c84、30bd30入口和30c104返回仅作为比较目标。主入口目标或中间输出目标被扰动时，预测音频不变；扰动早期源组或增益控制时预测改变。

成功B捕获13256记录，即3314组四点事件，五声部；正常exit 0，无挂起上下文或错误，13263次Continue审计。2548978项检查零差异；三个中间组636288采样核对相同，最终组件主组212096采样相同。333次Rattle触发，40752个输出样本受附加信号影响，73个控制回零活动尾块匹配。

27项扰动测试全部符合预期，旧两点Rattle数据回归348482项零差异。五条计算组件分轨独立读取，与对应原生float32输出共212096采样字节同。

只验证merge、primary、envelope、filter关闭及空EQ路径；主动分支明确拒绝。更早cross音频输入、模型源表和部分控制仍观察，尚未连接pass102的同次完整声部源。不得把不同运行的结果拼成独立完整钢琴验证。

完整B原生WAV与参考均148224帧，但97447个交错采样不同，最大24-bit整数差10，首差异帧13036，归一化RMS差1.42011541579061e-7；严格失败。此结果不能证明网页或完整立体声音色一致。

A次因依赖模块未在LLDB回调命名空间绑定而没有采集记录，明确失败；目标正常exit 0后修正回调并新建B运行。A完整WAV176385个采样不同，最大整数差6306。所有失败保留。
