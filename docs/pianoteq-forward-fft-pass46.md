# pass46：完整正向128点FFT接入卷积乘加

新增 [real-fft-finalize.mjs](../dsp/real-fft-finalize.mjs)，将pass45的四lane核心组合为原生未排序的128点实数频谱。默认同一次运行中，240次正向FFT的计算结果直接供给512次CABN频域乘加，并核对29次逆FFT的输入；296576项逐位同，完整原生PCM符合官方基准。

逆FFT时域输出尚未计算，时域输入/脉冲响应初始化仍观察，完整卷积、全部模型/预设和网页声音仍未完成。

## 四lane组合与特殊端点

`81d9e4` 按四组处理核心输出：每组把相邻实部与当前虚部排列为四路复数，旋转其中三路，再执行四路蝶形。组间需要携带上一组末尾四个值，首组则先补零，随后单独写回DC、Nyquist及四个半根号二边界项。实现逐步float32舍入，并保留各原生FMA的位置。

初版最终频谱在64次初始化变换的8192项中有140处差异。实际首组虚部采用两次乘法加一次普通加法，后续三组才用FMA。修正后初始化与播放窗口的完整正向输出均逐位同，原诊断 `pass46-finalize-diagnostic.json` 保留，没有放宽容差。

组合系数共96项，按固定计划生成：先把 `-2π/128` 舍入float32，先乘旋转路号1/2/3并舍入，再乘频点位置并舍入，最后sin/cos并转float32。负零也保留。把这两次乘法合并会改变部分系数。核心32项旋转系数和这里96项组合系数均自行计算；原生初始化调用路径尚未动态绑定，验证仅覆盖当前固定尺寸和平台。

[完整正向重放器](../scripts/pianoteq_replay_real_fft.mjs) 只接受当前128点、实数、未排序计划；不支持有序输出、其它尺寸或逆变换。它重用pass45两个已通过完整PCM审计的原始捕获，不修改旧报告：初始化窗口32768项，播放窗口24576项，共57344项，包括系数、中间核心及最终频谱检查。这些不是新执行的原生实验。

## 同一次运行中建立频谱来源

[连接捕获器](../scripts/pianoteq_capture_fft_products.py) 用四个只读硬件点记录FFT入口/返回与CABN乘加前/后，通过实际缓冲地址匹配来源。[连接重放器](../scripts/pianoteq_replay_fft_products.mjs) 自行计算每次正向FFT，并把结果保存到频谱表。乘加的两路频谱必须存在已计算的生产者；找不到时直接失败，没有退回读取原生频谱作输入。

累加历史独立携带；观察到逆FFT消费该缓冲后，标记其旧频域表示失效。下一次使用时自己清空，并与原生乘加前的零缓冲核对。逆FFT的输入还与自己累加的频谱比较；逆FFT返回的时域数组不参与本轮计算，也没有被伪装成独立预测。

默认窗口共240次正向FFT、512次乘加、29次逆变换输入核对、32次累加器初始化/清空：

| 比较内容 | 项数 |
| --- | --- |
| 正向FFT输出 | 30720 |
| 乘加两路计算频谱、调用前及调用后累加值 | 262144 |
| 逆FFT输入 | 3712 |
| 合计 | 296576 |

这比pass44继续前进：频域乘加不再依赖观察到的源频谱或核频谱，但它们各自的时域输入和脉冲响应内容仍是观察边界。
