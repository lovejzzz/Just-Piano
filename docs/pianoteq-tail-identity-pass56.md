# pass56：工作输出到主线程消费的块身份绑定

本次用同一运行中的对象身份与代次，查明512帧尾部工作结果的消费时序。已开始消费的23代结果，均在其输入起点后1024帧开始被读取；其中22代完整读取，最后一代只观察到首64帧。此结论限于本次固定配置与调试调度，不是任意实时负载下的固定延迟保证。

## 同次证据

[采集器](../scripts/pianoteq_capture_tail_identity.py) 在外层队列点 `0ef75c`、工作节点入口 `7ccca0`、返回 `7cd0e4` 和末级PCM使用四个硬件断点。主线程读取当前输出块地址、位置和实际64帧切片；工作入口记录目标矩阵地址，按块内矩阵偏移8字节识别所属块，返回时读取完整三行512帧结果。

[核对器](../scripts/pianoteq_replay_tail_identity.mjs) 按事件顺序为每个目标块保存返回结果及代次，在主线程位置0处绑定实际相同地址，然后核对全部64帧切片。指针可复用，因此不能仅凭地址跨越所有调用匹配：已消费代次不得二次消费，未完整消费代次不得被新工作结果覆盖，切片位置必须连续。

没有搜索样本相似度，也没有挑选最相似时间偏移；1024帧偏移由已绑定代次和输入时钟独立计算。

| 观测 | 结果 |
| --- | --- |
| 工作调用 | 24次完整入口/返回 |
| 主源重组与工作入口 | 24包，110592项float32逐位同 |
| 已绑定工作结果消费 | 177个64帧切片，33984项float32逐位同 |
| 初始输出 | 两个不同块，共16个切片，3072项为零 |
| 帧与工作时钟 | 241项一致 |
| 合计 | 147889项一致 |

本次共有三个输出块轮换复用。工作0返回的块首次在全局1024帧消费，工作1在1536帧，工作2在2048帧；同一对象每三个工作调用复用一次。前两个512帧输出块为初始化静音。采集到12352帧时，代次0到21完整消费，代次22消费64帧，代次23已经返回但还未进入消费；不把后两代说成完整消费验证。

这解释了pass54按输入起点后512帧对应的失败。该失败记录仍保留；这里新增的是同次身份和代次证据，而不是重新拟合旧运行的时间偏移。

## 实际音频与负对照

原生进程54792正常exit0。启动后一次在已设置的主队列硬件断点处异常暂停，按既定保护只继续该已知地址，之后窗口完整并正常退出；未放宽到其他异常地址，也未写入目标内存。

完整113152帧、48kHz、双声道24-bit PCM与官方基准逐字节相同，PCM SHA-256为 `1907f854d5c427908038ee9629a5c8997facbb71242e30b94874fc0553a4c9d6`。12352帧末级浮点观测重新编码与同次WAV及参考前缀一致。

七个负对照全部拒绝：消费样本、工作返回样本、输出块身份、消费位置、未消费代次覆盖、删除工作入口及不完整窗口。样本修改的检查失败，身份/时序破坏被结构约束拒绝。

工作结果本身仍由原生程序生成。本轮查清已测配置的交接与消费映射，尚未自行计算512帧工作卷积、1024点逆变换或完整钢琴声音。网页音源未因本轮研究发生变化，未最终合并或部署。

私有证据：`debug-pass56-tail-identity/`、`pass56-*`。未使用Pedalboard，原应用未修改。
