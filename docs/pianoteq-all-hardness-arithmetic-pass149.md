# 总硬度分段算术与端点验证失败（pass149）

2026-10-17。恢复非零 All 的具体计算，独立 ARM 指令转写对照 308232 个 float32 值全部同；补正普通硬度表的最终夹值。官方程序完成五份新 WAV，但新进程参数读回失败，**不能把这些 WAV 算作非零 All 声音验证通过**。非零 All 仍未接入已验证声部分支。

## REA 与具体方程

新的 Ghidra 12.1.4 分析正常 exit0，目标仍为既有只读 ARM64 文件。函数 `FUN_100065fe4` 的证据 ID：`ev_c0b03f41d1df3e8949003e3e6d74916e83654727a849ebda8aa497cf11211111`；私有报告 SHA256：`ba263ccec1dd25a55551cddd33410cefddaf6fb7438520a24084d43a4bbf74cc`。反编译的 lane 拼装和条件选择另用 ARM 指令核对。

`0662b0..066350` 对三组已算出的 Piano/Mezzo/Forte 增益执行同一分段变换。令 f 为 float32 舍入，a 为总量标量加音高曲线后夹到 [-1,1] 的值：

```
若 a == 0：保持原始组三个增益 g
否则：
  b = clamp(f(g * f(1+a)), 0, 2)
  若 a < 0.5：结果为 b
  否则：t = f(f(a-0.5)*2)
        结果为 FMA32(f(2-b), t, b)
```

All=0 分支不能提前把组增益夹值；夹值还发生在之后基础曲线相乘所得的各节点产品。`066754..066780` 将两套硬度表最终节点夹在 [0,2]。相邻编辑表另有 [.1,1] 限制，本轮没有把它混入正常硬度表。

新增 `dsp/hammer-all-hardness.mjs` 包含分段函数与最终产品夹值。`archiveHardnessAt69` 只接入后者，继续拒绝非零 All；没有以静态算术恢复为由扩大运行验证范围。

## 独立指令转写对照的含义

`scripts/pianoteq_all_hardness_oracle.S` 把该段标量与双 lane 指令转写到自己的可执行程序，调整寄存器以符合调用约定；C driver 批量传入和返回 float32 位模式。它不附加 Pianoteq，不读取或改写目标进程，也不是新的 Pianoteq 内部轨迹采集。

102744 组有限输入（三组增益及 All），共 308232 个输出逐位同，包括零、符号零、阈值相邻值、上下界和随机浮点输入。`instruction-replay.json` 明确标记 `instructionTranscriptionOnly=true`、`newNativeVoiceCapture=false`、`allHardnessAudioEquivalent=false`。该结果证明转写算术一致，不证明实际程序在当前预设进入了非零分支。

## 新实际音频与失败边界

从原 dry FXP 创建五个独立本地副本，仅改变已解码的 s10 字段（-1、-.5、0、.5、1），更新文件内容校验并完整重新解码；其它解码字段保持一致。程序、原预设和模型文件不修改。

官方原版 CLI 使用相同 MIDI 导出五份 48 kHz/24-bit、无 dither 的实际立体声 WAV，均 exit0。文件确有差异，部分长度也不同，但随后 fresh-process `getParameters` 读回 minus1 时：

- `hammer_hardness` 名称为 `(locked) Hammer Hardness`。
- 预期 normalized=0，实际 normalized=.5、显示 0。
- 读回断言失败；只读回了该端点，之后没有继续其它锁定参数尝试。

因此不能证明这些文件差异对应预期的官方 All 参数端点，也不能用它们定量验证上述方程。失败及实际文件均保留，没有将锁定界面的读回推断成 DSP 内部必然没有变化，也没有绕过限制。该拥有的读回进程已正常退出；既有冻结调试进程没有改动。

## 普通分支回归与剩余范围

产品夹值接入后，原 A4/All0 场景的源表及硬度边界保持吻合，连续链 14214461 项比较零差异。30 条实际分轨独立读回 1272576 个采样全同；npm test 通过。新合成测试分别覆盖正常表生成分组、超限产品夹值和 All 分段，不把合成夹具标成原生覆盖。

本机证据目录 `pass149-all-hardness/` 保留 REA、指令回放、FXP 副本、WAV、参数读回失败和普通分支回归；商业字段与音频均不加入 Git。仍缺非零 All 的实际内部数值轨迹和独立音轨等价，完整接触耦合、全部预设及网页最终声音也未通过。本轮不使用 Pedalboard，不合并、不发布。
