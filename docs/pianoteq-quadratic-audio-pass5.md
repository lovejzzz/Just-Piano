# Quadratic Effect 和频预测的干声音频干预（pass 5）

日期：2026-10-15。官方 Pianoteq standalone 9.2.5/20260909，原应用不改动，无 Pedalboard 或插件宿主。

## 单变量控制与保存验证

自有 GUI/API 8141 由正常 Devices 操作启动到 audio running。先将 NY Steinway D Mix 的五个效果开关关闭，全部 215 项与此前 `audio-pass5-dry/dry-restored.json` 一致。基线 Quadratic Effect 未锁定，normalized 为 `0.5698242783546448`，显示文本 `1.00`。只将 `quadratic_effect` 改为 normalized `0.0`，实际文本为 **`0`**。

确认 modified、等待至少 3 秒后，保存唯一临时 bank 的 full FXP，复制为证据 `quadratic0.fxp`，删除临时 bank。全新无音频输出的 headless 8142 实例读回全部 215 参数，与保存前预期逐项一致；相较 dry 基线只有 Quadratic Effect 这一项变化。验证进程正常退出 0。没有改变 post_effect_gain、噪声、其它物理参数或用户偏好。

基线 FXP 是已完整读回验证的 `audio-pass5-dry/dry.fxp`，效果 1/2/3、reverb、limiter 五个 switch 均关闭。机械声和乐器内部处理仍在，“干声”不等同于直接访问内部单一弦模态。

## 渲染前的预测与测量约定

静态分析提出生成记录频率 `Fnew = Fa + Fb`，幅度权重含 `q * Wa * Wb`。在看本次输出前保存 `predeclared-design.json`：从 q=0 输出识别前六个主分音峰 `Fa`，固定全部 21 个 `Fa+Fb`（含 a=b），比较 q=0 与 q=1.00 在这些相同频率的谱幅；**不根据 q=1.00 的新峰重新调整预测频率**。这不是把琴键的等分律基频直接作为全部内部模态频率。

MIDI 45/A2、69/A4 各在 q=0 与 q=1.00 渲染一次，共 **4 次全新官方 CLI**；均 velocity 96、CC64=0，0.5 秒起音、10.5 秒松键、13 秒 MIDI，48 kHz 双声道 24-bit PCM、dither OFF、不归一化。每次等待前一进程结束才启动下一次，全部 exit 0。最高峰值 -10.871 dBFS，没有样本 clipping。

## 固定预测频率的结果

长尾 2–10 秒中，MIDI 45 的 `F5+F6 = 1210.387790 Hz` 与 `2F6 = 1320.555179 Hz` 在 q=1.00 分别约为 -125.45/-121.71 dBFS，而 q=0 的同频复投影接近数值/泄漏底部（-173.88/-162.68 dBFS）。这些值是相干谱投影，不能据此声称单个 PCM 样本有低于 24-bit 的量化精度。两目标距所选最近主分音分别 5.15/6.22 Hz。

MIDI 69 的长尾目标多数已很弱，没有普遍出现可用的和频增幅。不能把所有 21 个目标或两个音区都标记为已验证。完整 42 个候选结果，包括阴性、重叠和极低幅项目，保留在 `spectrum-results.json`。

## 能支持与不能支持的结论

该单变量干预在若干事先指定的 `Fa+Fb` 频率附近得到与静态和频生成预测一致的增强，同时保留完整阴性和未分辨结果。它比“参数改变了声音”更具体。

但外部 PCM 的单个主峰不等于静态数组中的全部内部记录：同度多弦、弱模态、阻尼、有限窗泄漏和多组和频重叠都可能影响对应关系。比如 MIDI 45 的 F4+F6 与 2F5 仅差约 0.028 Hz，早窗无法分开；不能把该区域的一个增强分别当作两次独立验证。大量低次 A2 和频接近已有主分音，也不能独立分辨。极低幅谱投影不宜用作主要证据。

静态分析还发现 q 会进入后续分量频率扩缩过程，因此不预测整个差分 PCM 只含新增和频。这 4 次渲染也没有单独验证 `Wa*Wb` 的定量比例、每个内部 `(a,b)` 记录、精确阻尼，或完整琴槌接触力/弦反馈/制音毡耦合。
