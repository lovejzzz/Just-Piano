## 计算

`applyNativeReflector` 接收 column-major 交错复 double 矩阵、明确的左右方向和子区域。范数复用上一轮的 SIMD8 前缀/标量尾部算法，β=−2/norm。先以完整复乘计算 (β+i0)v，不能将它换成两个标量乘法；复乘内部保留 FMA 和符号零。

左侧工作向量为 Aᴴ(βv)，右侧为 A(βv)。矩阵向量积按原列/行顺序计算，每个复乘结果先舍入，再与工作向量分开相加。秩一更新分别为 v·workᴴ 和 work·vᴴ，复乘的 FMA 操作数次序及最后的独立 FADD 都保留。有限输入产生未支持的非有限中间值时拒绝，而非调用不同算法。

`reduceNativeHessenberg` 按 4ee5a4 的不累计特征向量分支，对 start=1..order−2，提取上一列尾部、构造反射向量、左更新 rows[start,n)/columns[start−1,n)，再右更新 rows[0,n)/columns[start,n)。不把消去位置强制清零，保留实际舍入残差。返回每阶段向量、工作区及 β，明确 `nativeQrIterationComputed=false`。
