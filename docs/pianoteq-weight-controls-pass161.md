# 谐波权重四个控制的存档生产（pass161）

2026-10-17。新增 `archiveWeightControls`，并通过统一模型快照的 `archiveNoteWeightControls` 暴露。该步骤替换权重变换调用的四个寄存器输入，未声称整个谐波权重生产闭合。

ARM调用点4cb5bc..4cb68c以及三个helper确认：

- s0：A1024或B18c8非零时读取A1020，否则为1。它控制基础频谱曲线的补权重，不能无条件读A1020。
- s1：B17d8(note)与A8a8(note)先float相乘，再与A8a0 float相乘，限制至float(0.1)..10。来自2a4514。
- s2：B1828(note)，来自667e54。
- s3：B1878(note)，来自92b770。

曲线运行属性仍由调用者显式提供，不能从压缩存档版本猜测。支持普通标量曲线及常值，缺字段/模式即拒绝。统一上下文接口读取其自身模型/预设快照。
