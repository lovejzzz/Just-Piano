# 第五轮：硬度后的模态激励谱计算

本报告独立核对 `FUN_100692ffc` 的硬度求值后半段，重点为 `pass4-main-excitation.txt` 第 1260–2360 行，并以原生 ARM64 指令核验关键算术。分析对象仍为本机 Pianoteq 9.2.5 ARM64 只读副本。

## 可确定的计算性质

这段代码在 note-on 准备调用链中，根据力度、硬度曲线、模型表格和模态坐标修改数组。硬度之后主要循环的边界是输入描述 D 的两个数量：`D.u32[0]` 和 `D.u32[1]`；没有由音频块长控制的时间推进，也没有在该循环读写琴槌质量、压缩位移及接触速度状态。这里恢复的是**预计算的模态权重/激励谱变换**，不能把 `powf` 或谱变亮解释成已经找到了逐样本琴槌接触力。

这也不证明整个程序不存在逐时步接触求解。该结论仅约束已核对的函数路径；完整渲染的其它状态反馈仍须独立追踪。

## 基址与输入

| 符号 | 实际来源 |
|---|---|
| P | `param_4`，note-on 生成的描述对象 |
| G | `*P`，逐音符模型记录 |
| D | `param_5`，本函数修改的数组集合 |
| J | `D.u32[0]`，每条记录中 float 数量 |
| N | `D.u32[1]`，进入本段时的记录数量 |
| k_i | `(*(float **)(G+0x7b8))[i]`，非整数的模型坐标 |
| W | `*(float **)(D+0x70)`，本段最终原位缩放的数组 |
| T | `*(void **)(G+0x1240)`，附加模型配置 |

D 的 C 伪码类型为 `uint *`，故 `D + 0x1c` 在 C 伪码中是 **字节偏移 0x70**，不能误写成 +0x1c。其它数组指针按字节位于 D+0x20、+0x48、+0x98。

硬度 h 是第一套五节点曲线返回值乘本函数的公共倍率、模式倍率之后的结果；本函数还计算第二套 h₂。此处不能省略这些倍率，直接把 h 当 GUI 归一化硬度。

## 硬度到斜率：立方根并非接触压缩量

令 g=`float(G+0xf0)`，第一段为：

```text
t = (1 − 1.01 / (h + 0.00999999)) × g
b = float(T+0x274)
if b == 0: s = t
elif b == 1: s = 0
else:
    c = sign(t) × powf(abs(t), float(1/3))
    s = float(pow(double(float((1−b)×c + b×0)), 3))
```

原生核验地址 `0x100694010–0x1006940b8`。`powf` 的第二入参由位模式 `0x3eaaaaab` 载入；后面的 double `pow` 指数为 3。忽略浮点舍入时，后一分支近似 `(1−b)^3×t`。因此这处立方根和三次方主要重标度谱斜率，不能据此声称实现 `F=Kδ^p` 的琴毡压缩力。

第二套硬度也生成 `t₂=(1−1.01/(h₂+0.00999999))×g`，并可通过可选输出指针返回。以上中间值均做有限数检查。

## 按模态坐标构造指数权重

程序按 s 的符号选基础表：s≤0 取 `G+0x248` 的 float 向量，s>0 取 `G+0x260`；记选中元素为 B_i。其倍率为：

```text
cB = 1−h             (s≤0)
cB = s/g             (s>0)
```

另有从 `G+0x190` 三值表选出并混合的参考量，再除以本函数前半段得到的参考标量；记这个商为 r。由于其物理身份和单位尚未建立，本文保留中性符号。

对 i=0..N−1，构造：

```text
L_i = clamp(s × (k_i−1−r), lo, hi) + cB × B_i
```

其中 s>0 时 `lo=0, hi=20`；s≤0 时 `hi=0`，下界是：

```text
lo = G[0x1014]
   + G[0xe7c] × P[0x34]
   + 2×P[0x2c] × T[0x4f8] × 0.115129255
```

所有方括号在此均表示该字节偏移的 float。关键原生指令 `0x100694d58–0x100694d90` 清楚地从 `G+0x7b8` 读取 k_i，做减 1、减 r、乘 s、上下界比较，随后加基础表贡献。

同一 i 循环还构造另一个临时 float 表 E_i，累加多个按 i 索引的模型向量及描述对象系数，包括 `G+c98`、`G+cb0`、`G+cc8`、`G+c80`、`G+ce0/cf8` 与 `(*P)+e60`。其中一条还调用 `100019a34(G+d38,3)`；由于部分曲线/系数物理身份未确认，不将 E_i 命名成琴槌位移或力。

随后按 k_i−1 在线性表 E 中重新取样。若 k_i−1<N，令 x=max(k_i−1,0)，a=floor(x)，a₁=min(a+1,N−1)：

```text
L_i ← L_i + ((1−(x−a))×E_a + (x−a)×E_a₁) × 0.115129255
```

超出上界的记录不加此项。常数约等于 ln(10)/20，是幅度 dB 变换的典型尺度；这里只据指令给出数值关系，不以常数单独证明每个模型表的单位。

最后每四个 float 调用 `FUN_10071033c`，其 `0x10071034c` 直接调用系统 `_vexpf`。因此变换后的值为指数权重 H_i≈exp(L_i)，不是未知非线性接触函数。之后以 1e−9 为门限，较小值置零：

```text
H_i = exp(L_i) if exp(L_i) >= 1e−9 else 0
for j = 0..J−1:
    W[J×i+j] ← H_i × W[J×i+j]
```

最终 scalar 写入在 `0x100695180` 邻近分支；主 SIMD 路径只是同一缩放的展开。无接触速度、当前弦位移或时间步出现在该式。

## 同段的其它数组操作

在硬度谱变换前，代码会按模式对 D+0x70、D+0x98 的相邻记录做混合。一条分支为：

```text
A_i ← (1−u)×A_i + u×exp(a×P[0x28]+b×input₂)×A_(i−1)
Φ_i ← (1−u)×Φ_i + u×(Φ_(i−1)+wrap(c×P[0x28]+d×input₂))
```

这里 A 来自 D+0x70，Φ 来自 D+0x98。它是沿记录索引 i 的递推，并且就地读前一元素；不是时间 n 上的弦反馈。只有当数组角色/单位进一步绑定后才能将 Φ 明确命名为角度。该分支包含 wrap 到约 [−π,π) 的形式，支持相位解释但不替代对象身份核验。

另 D+0x48 数组先整体乘 `param_1×P[0xc0]`。上述准备函数后半段还会追加模式、重新分配数组以及拆分记录；本报告没有把它们概括为完整物理模型。

## 旧音符控制如何改变本次谱，而不是从 P/Q 求接触力

与 `pianoteq-render-coupling-pass5.md` 交叉核验：描述 P=X+0x2fb8，故 P+0x40 是重击控制 s_old（X+0x2ff8），P+0x44 是旧音符计数缩放量 t_old（X+0x2ffc），P+0x38 首字节为该重击分支标志。它们来自旧 voice 的年龄、力度和释放控制，不是当前模态 P/Q 历史向量。

本节 `s_old` 与前文硬度斜率 s 不同。

多分量 J>1 时，令 v=P.float[0x20]，本段首先使用 `v_eff=v×(1−s_old)`。这只用于下面的**跨分量权重混合**，五节点硬度函数仍使用原 v。令 q=max(函数第二 float 输入,P.float[0x28])，从 G+0x348 和 G+0x360 的两个向量线性混合得到 a₀/a₁/a₂：

```text
a_m = (1−q)×G348[m] + q×G360[m], m=0,1,2
A_m(x,z) = a_m×z + (1−a_m)×x
```

对每记录 i，只修改 j≥1 的 W_ij，参考同记录第一个分量 z=W_i0：

```text
若 v_eff < .5:
    d=2v_eff; w=2d−d²
    W_ij ← (1−w)×A₀(W_ij,z) + w×A₁(W_ij,z)
否则:
    d=2(min(v_eff,1)−.5); w=2d−d²
    W_ij ← (1−w)×A₁(W_ij,z) + w×A₂(W_ij,z)
```

这个循环不推进时间。它通过本次有效力度在三种跨分量混合之间插值。

随后公共硬度倍率先由两个控制分量取较小值：

```text
g₀ = min(1−P28 + P28×T_b8,
         1−input₂ + input₂×T_bc)
```

在 P+38 标志为 1 时，要求 t_old>0，并执行：

```text
g₁ = g₀ × [1 + s_old×(G380−1)×cos(2π f t_old)]
g  = g₁ / (1+2P2c)
```

未启用该标志时 g₁=g₀。这里 f 在 N=0 时为 G+0x78；N>0 调用 `1004174f4(D)`，正常分支直接返回 `F[J×D.u32[4]]`，F 是 D+0x20 第一向量。该 helper 没有从 O+0x58/O+0x80 模态历史求相位。g 再乘两套五点硬度求值，形成前文 h/h₂。因此重击会改变新激励谱，不能据余弦项宣称已恢复旧弦位移驱动的瞬时接触力。

## 击弦位置变化：奇次正弦级数的谱比值

本段比较 G+0xa8 的原位置 p₀ 与 `P.float[0xb8]×G.float[0xac]` 的新位置 p₁（容差约 1e−4）。发生变化时，读取 T+0xc8 的 float 系数向量 C，首元素 C₀ 为下界。对于模态坐标 k_i，计算两条奇次正弦和：

```text
S(k,p)=Σ_(m=1..K−1) C_m × sin((2m−1)π k p)
R_i = max(C₀,(1−i/N)×abs(S(k_i,p₁)))
      / max(C₀,(1−i/N)×abs(S(k_i,p₀)))
```

对非零 W_ij 通过 log/exp 更新，原生 `0x1006935c8–0x100693674` 给出的顺序为：

```text
z = G[f0]×k_i
W_ij ← G[d8] × exp(log(W_ij/G[d8]) + z + log(R_i) − z)
```

数学上约等于 W_ij×R_i；实现保持 log 域与相消项的舍入。原生 scalar 尾循环 `0x10069356c–0x1006935c4` 明确令奇数因子每次加 2，各次 `sinf` 输入分别乘 p₀/p₁，并累加同一 C_m。

另按配置位开启的分支，对 `sin(π p₁ k_i)<0` 的模态，将 D+0x98 相应 J 个分量加 π。这是位置变化所需的谱符号/相位修正。该式比“位置参与计算”的数据流描述更具体，但它是解析谱重加权，仍不是接触压缩位移的时间积分。

## 硬度后处理还会生成和频模态

`1006164fc(X,G,D)` 读取 G+0x7d0 的索引表、T+0x168/+0x16c 控制的配对范围。满足频率门限的记录对 a、b 逐分量 j 生成新记录：

```text
F_new,j = F_a,j + F_b,j
D48_new,j = D48_a,j + D48_b,j
W_new,j = C × Curve₁(F_new,j) × W_a,j × W_b,j
Φ_new,j = Φ_a,j + Φ_b,j
```

其中 Curve₁ 由 G+0x1028 准备，C 包含力度 v、G+0x10c8、G+0x10cc、X+0x68 与 T+0x164；可见倍率为：

```text
C = (v×G10c8×exp((1−min(v,1))×G10cc×.115129255)×21 / X.u32[68])
    × exp((1−T164)×−6.9077554)
```

若 X+0x2fe8 非零，还乘由 G+0xe60 表最大值与该控制组成的额外 dB 幅度因子。新记录的 D+0x48 还乘 Curve₂(F)，Curve₂ 由 G+0x1078 准备。这是明确的幅度乘积及和频/相位和组合，可描述为准备阶段的非线性频谱分量生成；不能叫作逐步接触力计算。

随后可能按每记录 J 个频率的平均值收扩：

```text
F̄_i = mean_j(F_ij)
F_ij ← F̄_i + (F_ij−F̄_i)×r_rand
```

r_rand 的基值含 v³ 和模型控制，再经 `1006da4b4` 随机配置修正；不从当前模态历史反馈。最后对全部 W 统一乘：

```text
gain_target / (sqrt(E_initial)+1e−20)
gain_target = T88×max(v,1)
```

`E_initial` 是追加记录之前 `1003d4a0c` 对 W 计算的平方和。该 helper 的原生 `0x1003d4a1c–0x1003d4a38` 直接做向量 `W×W` 累加及横向求和，故平方和身份已核实；`1002ccb98` 已由前轮确认原位缩放。

这显著缩小了本函数附近可能藏有接触求解器的范围：模型数组初始化、主要硬度/位置谱处理，以及紧邻的和频记录生成，都已展开为索引谱算术。仍需更上游 G 内嵌模型向量的生产者、未覆盖的附加分支和真实渲染反馈路径，才能判断程序是否采用其它接触近似或状态依赖算法。

新增 REA 原始证据文件为 `pass5-model-array-init.json`、`pass5-post-excitation-prepare.json`、`pass5-model-frequency-scalar.json`、`pass5-model-mode-map.json`、`pass5-model-matrix-map.json`，并有对应文本。两个 map helper 分别进行按输入坐标的表格插值、按有效记录频率的最近邻映射，不能视为力积分器。


## 与运行状态初始化的交叉核验

`pianoteq-render-coupling-pass5.md` 本轮新增的 `1009511bc → 100863008` 核验进一步支持上述数组角色：模型 K 的 +0x70 幅度、+0x98 相位，经过运行索引重排进入 V+0x160/+0x138 的首次初始化缓存。在普通初始响应路径，令 a 为幅度、φ 为相位、θ 为模态相位推进角，实际初始值为：

```text
P = a×sin(φ)
Q_pre = a×[cos(φ)sin(θ) + sin(φ)cos(θ)]
Q = R×Q_pre
```

即 Q≈R·a·sin(φ+θ)。另一输入模式初始化 P/Q 为零，并改为构造 U=a·cosφ、W=a·sinφ，最终输入系数为 C=W、D=(U·sinθ−W·cosθ)R。这把本报告的幅度/相位谱准备连接到实际二阶振荡状态或输入权重，而不是仅停留在数组形状。

字段具有阶段性复用：首次初始化后 V+0x160/+0x138 会被衰减 R 和倒正弦量复用。不能把后续同地址读取一律解释为原始幅度/相位，更不能据偏移相同主张相位实时反馈到琴槌。


## Quadratic Effect 已绑定到和频幅度的具体公式

此次命名有独立参数引用和状态复制证据，已不只是候选。参数注册元数据中的内部引用 ID 94（0x5e）为 `Quadratic Effect`（`metadata-table-decoded.json` index 94，Fine 为 95）。这与 RPC 参数列表的 `index:57` 不同，不能混用两种索引。`1003957c4` 的 `case 0x5e` 返回编辑状态 S+0xe38，Fine 分支为 S+0xe40。

直接状态复制链中，M 是 S+0x160 模型成员的副本，因此对应 M+0xcd8/+0xce0。`1007aa33c` 的 uint 指针索引 `[0x336]` 实为字节 +0xcd8，确实复制该标量；随后 +0x338（字节 +0xce0）的曲线深复制。`1005c8474(n,I)` 从 I 的虚表 +8 取得渲染编辑模型 M，并明确计算：

```text
q(n) = clamp(M.float[cd8] × E(M+ce0,n), 0, 20)
```

`1001c5320` 将结果保存到 G+0x10c8，`1006164fc` 的 fVar41 从同一字段读取并直接乘新生成幅度。这使“GUI Quadratic Effect → 编辑状态 → 渲染模型 → 逐音符 q → 和频谱幅度”闭环。

再令：

```text
v  = X.float[78]
N0 = X.u32[68]
z  = G.float[10cc]
d  = T.float[164]
C1(F) = G+1028 准备的曲线在 F 求值
```

C1 的基础模型来源由 `1002fd418` 确认是 B+0x2410；修改和频记录的 D+0x48 所用 C2 来自 `10054e4ec` 的 B+0x23e0。对程序选中的记录对 a/b 和分量 j，明确的幅度式为：

```text
F_ab,j = F_a,j + F_b,j
W_ab,j = q(n) × [21 v / N0]
         × exp((1−min(v,1)) z × .115129255)
         × exp((1−d) × −6.9077554)
         × C1(F_ab,j) × W_a,j × W_b,j
```

若 X+0x2fe8=u 非零且 G+0xe60 非空，再乘：

```text
exp(−2u × max(G.e60表) × .115129255)
```

相位为两条原相位之和，频率为两条原频率之和。这已经是 Quadratic Effect 的具体二次幅度乘积／和频生成计算；并不需要假设隐藏的“毡接触力”才能说明该分支。q=0 时该分支生成的新 W 全为零，原来已有的模态仍继续存在。

这一参数还有次级影响，实际音频验证必须计入：若成功追加和频记录，程序将 `q×mean(C1(F_ab,j))` 带入后续频率跨分量扩缩的随机基值。因此 q=0 与 q=1 的差分不仅可能包含和频幅度，也可能包含旧记录的频率分量扩散变化；已有峰值改变不能单独反证上述乘积式。后续统一幅度归一化使用的是追加前 W 的平方和，不会把新和频简单归一到固定能量。

### 和频生成的生效条件与配对范围

正的 Quadratic Effect 不意味着对所有模式对无条件相乘。`1006164fc` 先取索引向量 I=`G+0x7d0..0x7d8`，长度 M；L=`T.u32[0x168]` 为配对范围长度，r₀=`T.u32[0x16c]` 为首偏移。进入有实际分量 J>0 的生成路径须满足 M≥L；源索引还被检查在 D 原始子集范围内（末项 I[M−1] 必须小于进入时 D.u32[5]）。

对索引表中的位置 t 从 0 向上循环：

```text
a = I[t]
若 F_a,0 ≥ .5×T.float[158]：停止外层循环
for r = r₀ .. r₀+L−1:
    若 t+r ≥ M：停止内层循环
    b = I[t+r]
    对每分量 j 生成上式的 F_ab,j / W_ab,j / Φ_ab,j
```

新增记录的数量由这一索引范围和频率门限决定。q 本身不是上述频率/索引 guard；q=0 仍可能生成频率、衰减和相位条目，只是对应 W 为零。因而不能把参数关闭理解为“该准备函数完全不执行”，也不能把输出模式计数不变理解为没有效果。

条件、配对索引与幅度乘积均来自同一 `pass5-post-excitation-prepare` 函数；没有依赖函数名或外部物理模型补全。
