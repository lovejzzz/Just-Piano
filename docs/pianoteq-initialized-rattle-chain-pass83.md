# 源模型初始化与非零动态释放完整控制链：pass83

本轮将pass78的源模型初始化与pass82的动态Rattle、连续包络、复制和再击放进同一次运行，减少原生观察输入。这里的“完整控制链”限定于下述释放/再击路径，不表示完整发声、琴槌接触力或琴弦—制音毡方程已恢复。

## 初始化真正参与后续计算

[采集器](../scripts/pianoteq_capture_initialized_rattle_chain.py)固定六个硬件点：10035ef10击键前、10085ed9c动态源更新、10043e048初始化、1006e5360系数、100472fd0包络返回、1004604d4复制。为加入初始化，取消包络前置站点，只观察每块返回；重放必须从0携带自己的位置和样本数，不能依赖原生前置位置。返回处x20仍是块上下文，从其+10读取samples。

[DynamicReleaseVoice](../dsp/dynamic-release-voice.mjs)新增initializeModel，内部调用已有initializeReleaseModel，用源配置时长、资源多项式尾、全局scales、采样率与选中衰减行计算自己的模型；仅允许在渲染前初始化一次。refresh默认使用内部模型，process默认使用内部baseDuration/timestep。返回模型副本用于比较，原生目标不写回模块。显式模型参数仍兼容pass82，其原始窗口回归20487项保持通过。

[重放器](../scripts/pianoteq_replay_initialized_rattle_chain.mjs)调用上述真实运行模块，流程为：源初始化→动态x→自算D/rate/gain→自有连续包络→自有复制值→下一击旧release→自算再击控制。原生模型字段、系数、时间步、包络和复制值均仅作比较。源配置和模型衰减行仍观察，未声称来自所有工厂预设的完整运行时构建。
