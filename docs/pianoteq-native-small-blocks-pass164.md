# 原生复数小块求根（pass164）

2026-10-17。默认NY联合声源仍受原生QR缺口影响。本轮没有把独立Durand–Kerner结果当作原算法，改为恢复原生1×1/2×2块提取及二次伴随矩阵路径。三次与更高阶QR仍未完成，联合声源完整接线和新音频尚未通过。

## 实现

- `nativeComplexDivide` 扩展已恢复的9b39e0有限分支，支持一般有限分子：分母按二进制指数缩放、保留分开的乘法与FMA、除法及末次精确二次幂缩放。旧倒数入口及单分量路径保持原计算。
- `extractSmallEigenvalues` 恢复6f30a0的1×1/2×2提取。矩阵以交错复double、column-major传入；下对角与第一个对角模长使用FMA，第二个对角的向量平方/相加分开。严格小于 `2*tolerance*(diagNormA+diagNormD)` 才分成两个1×1块。
- 非分离2×2块使用trace和determinant形成复判别式，保留乘积/FMA次序及原分支复平方根，再依次写入加根和减根。没有调用JS三角/对数/独立迭代求根。
- `solveNativeQuadratic` 从原二次复系数形成伴随矩阵。ARM8d6d74/78按阶数步长写系数，故本接口column-major视图的首行是归一化系数，下对角为1。初版矩阵被转置，历史根仍碰巧通过；核对ARM后纠正为原布局，保留原报告并用v2重放。相同根不构成矩阵生产正确的充分证据。
- 非有限输入/中间乘积回退、系数零剔除（含平方范数下溢为0）、一般矩阵降阶和三次以上QR未实现，明确拒绝相应分支。

`coupledModes` 新增显式 `rootAlgorithm: 'native-quadratic-block'` 和必需的 `rootTolerance` 入口；选择该入口后遇到三次会拒绝，不会悄悄回退独立求根。其它既有调用仍走原已标注的独立算法，尚未声称全局求根器已替换。

## 验证

`historical-quadratics-v2.json` 从真实pass8的32组原始记录中明确覆盖全部14组N2，另18组N3标为未覆盖：

| 比较 | 数量 | 差异 |
| --- | ---: | ---: |
| 原生顺序的复根double | 56 | 0 |
| 最终频率/衰减float32 | 56 | 0 |
| 排序索引 | 28 | 0 |

复根是由系数自产，没有把捕获根作为输入。原生tolerance生产尚未闭合，回放显式使用3×JS epsilon；另用0再次比较，全部结果仍同。这只能证明这些样本在上述条件下保持2×2块，不能证明原生tolerance供应值。只修改捕获根目标后，预测输出不变且比较严格失败，保留changed-root-rejection.json。

`math-audit-v2.json`：20564组合成场景，61136个double与独立C/编译器运行库逐位同，无NaN语义替代。覆盖一般复除分子、符号零、极小/极大尺度，以及复数块、实/虚判别式和分离对角块。C块运算是独立指令转写，不是Pianoteq原生声部；不能据此扩展成全域QR通过。

完整npm test通过。新增测试确认矩阵布局、负零、正负实/虚根、显式算法消费、无独立求根数学回退及未支持分支拒绝。第一次fixture预期遗漏系数归一化中的−0，修正的是预期符号，没有改生产输出；另一次Node源码读取ETIMEDOUT在进程终止后原样重试通过，记录保留。末尾补充范数下溢拒绝后，受影响测试再次通过。
