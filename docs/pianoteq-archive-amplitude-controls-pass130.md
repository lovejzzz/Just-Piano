# 预设/基础模型到声源幅度控制（pass130）

2026-10-17。没有新的原生动态捕获或完整声音等价结果。

## 已核对的计算来源

复核私有不可变 ARM64 指令，不是新增在线 REA 查询：

- `102f88..102fb0`：传入 182960 的 s0=G+160、s1=cache+188、s2=cache+128；1829c8..1829d0 分别保存为 shape、shapeDb、addedDecay 对应的寄存器。
- `7a4154..7a4194`：基础 B+26f0 曲线在音符坐标求值，截到 [0,1]，存 cache+128。
- `0aefe4..0af050`：基础 B+25b0 曲线乘预设 A+530 曲线，再乘 A+488 标量，两个乘法各舍入 float32，截到 [0,100]，存 cache+188。
- `723b30..723b48`：基础 B+2790 曲线求值，经 `1c54a8..1c54c0` 存 G+160。
- `182af8..182b3c`：shapeDb 为零或分量数为一时 eta=1；其他情况将 shapeDb 与 float32 常数 `0xbdebc8e3` 相乘，调用 **expf**，再将 float 返回提升为 double。不是 double exp，也不能把未舍入的 dB 常数代入。

B2548 复合值中的十条曲线顺序对应连续 0x50 字节对象；本轮用曲线索引 1、5、7 分别取 B25b0、B26f0、B2790。A470 控制的成员 b/curves_ab[1] 对应 A488/A530，序列化成员顺序不能当作递增内存偏移。模型解码沿用 pass13/14 的已恢复 reader。

私有 `pass130-static-amplitude/manifest.json` 保存所读完整指令文件及五段相关指令的 SHA，片段留在本机。没有原生代码/数据/寄存器写入，没有 Pedalboard。

## 实现与接入

新增 `dsp/source-amplitude-controls.mjs`：`archiveAmplitudeControls` 从解码基础模型和预设计算 addedDecay、shape、shapeDb，再用已有原生 scalar expf 生成 eta；`sourceAmplitudeEta` 保留分量数/零值分支。曲线属性必须显式提供，当前只接受 flags0、special0、dimension1 的普通标量布局。

声源回放新增 `--amplitude-preset decoded-preset.json --amplitude-linear-curves`，同时要求已有自算极点/权重桥接及原生 pow。它使用唯一匹配的基础模型和预设值计算控制；原 G/cache 及幅度入口控制只比较。报告保留上游预设 SHA、每步求值和 expf 参数。

**本轮没有新捕获四条曲线的运行属性。** 普通线性模式是调用者显式指定的受限分支，当前实际输出与之吻合；不能从存档 version 推断其他模型一定具有相同运行属性，也不能据此声称曲线模式问题已全部解决。

## 历史原生记录与反向验证

正式 `pass130-amplitude-model-guard-b/baseline/report.json` 使用已有两个 A4 模式：

| 控制 | 自算值 |
| --- | ---: |
| addedDecay | 10 |
| shape | 0.8149999976158142 |
| shapeDb | 71.28001403808594 |
| expf 输入 | -8.206415176391602 |
| eta | 0.00027289724675938487 |

8 项入口控制 double 比较、6 项 G/cache float 比较全部相同。接入自身极点/权重后，各 108 项最终衰减、幅度、相位及 108 个频率绑定保持一致。72 次幅度 pow 再次由独立普通 C 程序核对全同。两个模式各一次 expf 也与独立系统调用逐位同，但只有 **一个不同输入**，不计为两个独立场景。

`pianoteq_test_computed_source.mjs --with-amplitude-model` 十三项反向检查通过：

- 原始衰减、权重、幅度目标、pow 结果及缺失 pow 比较项：各一项失败，预测不变。
- eta、shapeDb、cache188 比较值：各一项失败，全部自身预测不变。
- 上游权重改变：8 项不匹配、预测改变；预设 A488 标量改变：114 项不匹配、预测改变。
- 缺极点行、重复权重行：拒绝且无完整报告；旧 Math.pow 路径在禁止回退后失败。

默认浏览器兼容声源构造器在禁止 Math.pow 后也保持全部结果；`npm test` 通过。A 是模型接线验证，B 增加独立 expf 比较；全部私有输出保留，没有覆盖旧证据。
