# 独立分量生成与补行组装（pass157）

2026-10-17。接通显式单分量极点/权重→独立分量四表→按列组装/补行→混合端点/参考/归一化接口。**极点和部分控制仍由调用者提供，尚非完整模型或MIDI到音频；没有原生独立声部的新内部轨迹或实际音轨验收。**

## 原指令

沿用 pass151 REA/Ghidra `1026dc`，证据 `ev_b6766dc3b0d20a0a88d72d0717b280043a66573caedeeef882936219a3402d1d`，原报告SHA256 `303f58b17d9c979523a198ebc385a3956a0983126076c5aed90bf30581dbe892`。本轮核对既有完整 ARM listing 的独立分量循环与 `103458..103b10`，无新执行目标或写内存。

- cache+220幅度系数向量复制后，不足分量数时重复末值。`103580..35e8` 对分量幅度执行float乘法；频率、衰减和相位不乘该系数。
- 每个独立分量的 `182960` 是单列调用，且每次重新初始化自身相位随机序列；不能把所有列当成一次多列调用。
- `103458..34ac` 对两项均为float32 0.5的频率比向量，先将权重原向量改成 `W[min(2*i+1,last)]`。本轮将既有 `specialHalfRatioWeights` 接入该消费路径，未重新发明另一套权重算法。调用方仍必须提供该阶段实际使用的比值向量。
- `1038xx` 将四张独立单列表复制到各列，最终行数为分量实际行数最大值，超过原始模态行上限则拒绝。
- `103930..3ae0` 在各列中查找频率0作为缺失标记。最后有效行初始为0；若0之后又出现非零，原程序断言，此实现也拒绝。

缺失行 r、最后有效行 l 的 `103a20..3aac`：

```
delta = f(r-l)
frequency[r] = FMA32(firstFrequency, delta, frequency[l])
decay[r] = f(decay[l] + delta)
amplitude[r] = floatword(0x1e3ce508)
```

相位不被这个补行循环重写：已有零频率行的相位保留，新分配的缺失行保持初始+0。整列为空时首频率和初始衰减为0，得到0频率、递增衰减和tiny幅度，不能强行补首个非零模态。

## 实现

`dsp/independent-source-assembly.mjs` 提供：

- `constructIndependentComponents`：复用既有幅度行计算、恢复的double pow和相位序列实现，消费显式单列极点、经特殊分支选择的自身权重及明确控制。每分量独立调用相位生成器。
- `assembleIndependentSource`：幅度缩放、按列写入、最大行数、FMA补行、孔洞拒绝。原组件表不被修改。
- `independentSourceWeights`：验证输入并调用既有半比值权重选择。

`prepareEndpointSourceTables` 可选择 `independentSource.componentPoles` 进行分量构造，或用 `independentSource.components` 提供已有分量表；两者互斥。它会在blend<1时实际组装独立端点，并继续消费此前混合/参考/归一化/可选G相位控制；blend=1不生成无用独立分量。接口仍标记 `completeCacheVerified=false`。

另修正端点复制的输入限制：原程序blend=0/1直接复制，允许有限的带符号幅度；中间blend仍会进入对数幅度运算并拒绝负幅度。不能用中间分支的约束错误限制纯端点。

## 验证范围

独立C/system-fmaf对照10000组，**1397266个float32结果逐位一致**，包含权重选择和组装四表。覆盖5000组半比值分支、3110个空分量、101295个原始零频率行、不同分量长度、幅度系数末值复用、已有零行相位保留及幅度乘法溢出。模块复用既有权重helper后，完全相同corpus再次通过，报告分别保留 `math-audit.json`、`math-audit-v2.json`。

该C对照的组件四表仍是显式输入，**不包含新构造器的上游极点/控制生产验证**。构造器另外用单分量 `weight*sqrt(2*decay)` 的精确数值夹具检验，验证半比值权重确实传入幅度，并贯穿组装和全局归一化；非零随机相位测试确认各分量重新初始化后共享相同前缀。尚未把这些测试称为原生单分量声部轨迹。
