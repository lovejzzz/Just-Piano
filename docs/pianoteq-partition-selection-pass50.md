# pass50：输入环、分区选择和独立核频谱

[分区卷积模块](../dsp/partitioned-convolution.mjs) 从64帧输入块计算补零、正向FFT、输入环写入和分区槽位选择，再执行乘加、逆变换与重叠输出。新捕获中414次输入推入、46次调度、5208次乘加和131个非零输出块全部匹配：2057048项float32逐位同，另116081项状态、地址绑定、游标和时间戳精确相同。

这些比较来自一个64帧、九输入、三输出银行。原生完整PCM仍为已见过的差异变体，严格音频审计失败；不能把内部计算一致称为完整声音复刻。

## 输入复制与静音判定

`035a28` 把输入写到当前环游标指向的槽位，更新时间戳和空标志，写游标加一后环绕，并清除ready标志。非静音块经 `2a4334` 复制前64项、把后64项补零。调度中的变换命令取最近写入槽位并计算FFT。

本次九个输入环各16个槽位。模块独立携带游标、槽位状态和时间戳，核对每次推入前的旧槽位，以及每次调度前全部输入环的状态；没有从观察到的游标或选中对象反推计算结果。

静音判定 `6ebbe4` 先检查首尾样本；两者都等于零时，以四路FMA累加平方和，再按原生加法顺序求和并比较零。不能简单替换为 `every(x => x === 0)`，因为极小值的平方可能下溢。本次414块中393块首尾至少一项非零，21块全零，尚未取得“首尾都零、内部非零”这一分支的真实音频输入覆盖。

最初实现错误地把原生content字段的0理解为“已经变换”。实际输入复制前后及变换后的来源字段均可为1；该字段不能独自判定数组所处域。模块现在用自己的transformed标记携带计算状态，并另行核对原生字段。最初构造失败诊断保留，没有放宽数值容差。

## 分区选择及工作计划边界

输入环与核环都按下式选择延迟分区：

```
slot = count + cursor - 1 - lag
if (slot >= count) slot -= count
```

模块要求 `0 <= lag < count`，独立推导每次乘加的输入槽位、核槽位、目标对象和比例。非空输入及核、非零比例才产生乘加。目标首次被使用时自行清零；没有使用原生乘加前数据作为累加历史。

本次初始化配置含九个核环、九条路由和一个156条命令的工作计划：九条输入变换、144条候选分区乘加和三条逆变换。**这份编译工作计划及路由配置仍从初始化观察取得，计划生成尚未恢复。** 与pass49相比，本轮自行决定每块实际执行哪些乘加及其环槽位，不再逐调用读取原生选择作为计算输入。

## 由时域核计算频谱

[核输入绑定工具](../scripts/pianoteq_build_kernel_inputs.mjs) 将pass49同一预设和采样率下的初始化时域核块，与本次核对象对应起来：147个首次乘加之前的正向生产者中，序号0至143的144个结果分别与本次全部144个核频谱逐位吻合，且无歧义。

绑定文件保存时域float32的原始位，保留负零，并绑定两个捕获文件的SHA-256。[严格重放器](../scripts/pianoteq_replay_convolution_scheduler.mjs) 必须显式提供 `--kernel-time-inputs`；它从这些时域块重新计算核频谱，初始化观察到的频谱仅用作比较目标。模块没有回退读取原生核频谱作计算输入。

这属于**跨运行的初始化连接**，不是本次运行中再次采集了核的时域生产过程。时域IR本身如何由预设生成仍未实现；不能由144个频谱匹配推出全部模型或预设已经解出。

## 实际音频与负对照

本轮一次原生采集使用四个主线程固定硬件点：输入推入、银行调度、乘加调用和归一化结束。进程31648在固定乘加点发生一次受限继续（当时1348条记录、无回调错误），最终正常exit0；重放检查完整消费全部预计乘加和输出。

完整113152帧、48kHz、双声道24-bit PCM为 `19481af4235d57e6db522290e2d90dd07fd8cf548c0264f549b1e3863422c84d`。与官方参考仍有148623个交错样本不同，最大整数差15089，首次差异frame4611，归一化RMS差8.383565726205929e-05。严格音频通过数为零，原因尚未确定，没有更换参考。

八个负对照全部失败：推入游标、调度游标、选中缓冲标识三个单字段变化各引起一次不匹配；逆变换、输出、初始化核频谱三个目标各改一ULP也各引起一次不匹配。时域核输入改一ULP引起15259项不匹配，说明核频谱确实重新计算；删除首个推入记录则被顺序检查立即拒绝。目标数据的负对照显式重建了对应测试夹具的SHA绑定，未修改原始捕获。

## 剩余工作

编译计划/路由的生成、IR时域初始化、其它分区尺寸、尾部调度、CABN外层传输和完整音频差异仍未解决。本次只覆盖46次64帧银行调用，尚未建立其与整段PCM全局帧的精确对应；不能认定已覆盖frame4611的差异起点。后续必须取得全局帧位置并延长到差异起点之后，检查较长分区和尾部输出。完整琴槌—弦—制音毡接触方程、全部模型/预设及网页声音等价性也未完成；模块仍处研究目录，尚未合并或部署为完成版本。

私有证据为 `debug-pass50-convolution-scheduler/`、`pass50-*.json` 及REA快照；仓库仅提交独立实现、重放工具和报告。
