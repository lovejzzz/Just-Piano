# pass59：主线程源、尾部工作银行和消费队列的同次闭合

从同次主线程九行64帧源块出发，独立重组输入、计算尾部银行并排队输出；48代结果的全部384个消费切片与原生逐位一致。原生工作输入、工作结果和消费切片仅作核对目标，未送回计算状态。

## 可复用的64帧处理器

新增 [QueuedTailConvolution512](../dsp/tail-convolution.mjs)。构造时独立生成IR频谱并初始化银行与两个静音输出块；每次只接受九行64帧输入：

1. 从当前输出块读取对应的三行64帧切片。
2. 写入自己的九行512帧输入队列。
3. 每满八块，计算完整工作银行，将生成的输出排在两个块队列尾端。

固定双块启动队列产生本次已验证的1024帧源到消费偏移，输入按相对512帧代次推进。处理器不接收原生线程事件、目标地址或原生输出值，计算在源块到齐时执行。它是当前固定配置的数学实现，未声称复刻所有实时线程调度，也尚未接入网页声源。

[重放器](../scripts/pianoteq_replay_tail_chain.mjs) 用该处理器处理完整400个主源块。另一套检查按本次原生目标块地址及代次绑定工作调用和消费，要求位置连续、不得重用未消费完的代次、不得重复消费，并逐块核对独立处理器返回的代次与位置。因此没有仅按最相似偏移寻找对应。

## 同次采集与边界

[采集器](../scripts/pianoteq_capture_tail_chain.py) 同时使用四个固定硬件点：初始化时域复制 `2a4334`、工作入口 `7ccca0`、主队列 `0ef75c`、末级PCM。初始化IR按对象身份绑定，第一次工作入口后关闭复制点。

为保持四点限制，上一工作结果在同一节点下一次工作入口读取，记录为 `completed`，不是伪称观测到了函数返回时刻。此时节点时钟已推进512，目标块尚保留上一结果；重放分别核对该结果和实际消费片段。计算结果在主源包到齐时已经可用，后续原生结果观测仅用于验证。

采集25600帧。主源形成50个完整输入包；前48包有工作入口、工作结果及完整消费证据，最后两包独立计算后仍排队，未把它们计为已核对的工作输出。

IR时域分区和编译计划仍从本次原生初始化取得。九行主声源仍观察；处理器没有恢复其上游完整琴槌—弦—制音毡计算。
