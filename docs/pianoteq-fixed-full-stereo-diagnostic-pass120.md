## 连续独立计算与真实音频

新增固定点回放器，不把B协议的逐块动态轮换记录伪装成固定点。每个声部从年龄零开始计算终端包络、活动起音时间包络、合并/还原、三组空间网络、静音计数与辅助分配；自己的结果写四个共享延迟缓存。全局每块独立读缓存，再接反馈注入、全局路由、完整卷积和干声后处理，生成左右声道及PCM。

共享缓存首个观察发生在首个全局读之后：四个缓存各三行、head64、逻辑空标志全15。该初始头明确为观察值；首个已读输出按发声前逻辑空状态生成零，并在cabinet端点核对。后续读写及有效标志由自身推进，观察到的缓存元数据只比较。

修正后的B回放报告：14421825项数值比较零差异，其中27918项double精确比较；1093个活动主包络块、2904个起音结束后块，次包络活动数0。265个非空IR频谱自行从观察的时域IR生成，277032次头部及28527次尾部卷积乘积。3314个声部块均路由；实际没有rendered但不路由、无render的voiceExit，不能宣称这些分支已动态验证。

空间网络包含1178个全组非活动块和19个部分组非活动块。这是本次真实捕获的数值诊断，补充了pass119仅静态/合成的证据；睡眠计数、网络状态及实际输出同时比较。它不消除本次捕获被拒绝的事实，也不覆盖未完成fade期间的静音分支。

完整128512帧PCM与同次原生零差异，观察PCM编码校准亦零差异。另用Python独立读取实际导出的RIFF文件及原生文件，257024个PCM24交错声道采样字节全部相同，PCM SHA256均为e9255f062d2c9838b35762bbc50138c5b8af3e5cd3951e88a32dff25ea932d70。

这条计算链仍从观察的Rattle输出音频开始。部分模型与启用控制、空间系数、路由表、全局两行输入与反馈、IR时域源及编译计划仍观察；double exp仍为此前的候选实现。不能称为从MIDI和预设独立产生完整物理声源，不能跨运行拼接先前上游组件作此声明。

## 验证器首次失败与修正

A回放完整PCM已同原生，但有2008项cabinet-source-descriptor错误。原因是验证器把matrix.pointer（采样缓冲区地址）误作B+288的矩阵描述符地址。原始matrix读取器明确从descriptor+16读取pointer；冻结的采集回调在每个cabinet停止处已经断言实际x2等于B+288。

没有修改或补写原始捕获。B回放改为检查九行连续采样布局和实际采样缓冲区身份，报告明确标注描述符地址未作为独立字段保存在记录中、仅由冻结采集器断言。A失败报告保留，没有追溯改成通过。该修正没有改任何DSP公式、音频比较或容差。

## 八项反向验证

新增可复用的真实捕获反向测试驱动，每例保存实际进程退出码、输出及报告，原始捕获不变。八例均符合预期，驱动正常exit0：

- 单改key静音计数比较目标：恰好一项sleep-input差异，生成PCM不变。
- 单改PCM比较目标：恰好一项final-stereo及一项编码校准差异，生成PCM不变。
- 改真实声部输入：113187项数值差异、2944个生成PCM声道采样改变；观察编码校准仍相同。
- 错全局块号、删末块PCM、移除一次观察的Continue审计均明确拒绝。

这些验证说明目标值没有被用来修正生成音频，也检查了完整长度和停止审计；它们不改变原始捕获与正常参考仍失败的结论。
