# pass58：完整512帧尾部工作银行

独立计算尾部银行的完整工作输出：48次调用共73728个float32输出样本与原生逐位相同。此轮从观测的工作输入和IR时域分区开始，不把原生输入频谱、乘积、逆输出或尾部样本注入计算。

## 同次IR初始化与运行

[采集器](../scripts/pianoteq_capture_worker_bank512.py) 在初始化时的复制函数 `2a4334` 读取512帧时域源，按实际FFT对象身份保存。第一次工作节点入口获得真实银行配置和IR环槽，只为非空槽绑定该对象的时域源，再自行补512个零；随后关闭初始化断点。

另外三个硬件点是工作节点入口 `7ccca0`、返回 `7cd0e4` 与末级PCM。工作节点限定独立工作线程、512帧、九输入及单银行，第一次时钟必须为0；不使用主线程初始化时调用的其他512帧节点。

本次银行有九条路由、三路输出。前三个输入/IR环各15槽，其余六个环各13槽，共123个IR槽，其中121非空。单步编译计划135条命令：9次输入FFT、123项路由/延迟积累和3次逆变换。48次调用跨过两种环长的多次回绕。

## 独立计算

[银行实现](../dsp/partitioned-convolution.mjs) 现在提供固定64帧与512帧两个入口，复用已经验证的输入静音判定、环形索引和命令执行顺序，按块长选择128点或1024点FFT、逆变换与重叠相加。

[重放器](../scripts/pianoteq_replay_worker_bank512.mjs) 先从捕获的时域分区生成全部IR频谱。原生IR频谱仅用于核对生成结果，随后运行使用独立生成值。每次将九行时域工作源推入自己的输入环，按编译计划计算正向变换、按float32融合乘加顺序积累、逆变换、1/1024归一化、重叠相加及历史推进。

空输出同样从独立历史读出、然后清零历史，未省略启动阶段的五个空输出。返回时三路结果全部与原生目标矩阵核对；没有用工作返回样本更新内部状态。
