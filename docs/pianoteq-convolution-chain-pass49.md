# pass49：同次正向FFT、乘加、逆变换和重叠输出

[连接重放器](../scripts/pianoteq_replay_convolution_chain.mjs) 将前几轮模块串在同一次捕获中：从时域输入计算正向频谱，供给频域乘加，累加结果供给逆变换，再计算归一化和连续重叠历史。131个非零输出块、三路历史共2050176项float32逐位一致，完整消费了窗口中的全部累加器。

原生运行正常exit0，但完整PCM依然是已见过的差异变体，因此严格音频审计失败。这里完成的是限定卷积窗口的计算连接，不是完整音源、全部预设或网页等价性验证。

## 四个只读观测点

[捕获器](../scripts/pianoteq_capture_convolution_chain.py) 保留四个固定硬件点，并限定LLDB线程索引1：

| 位置 | 观测内容 | 计算依赖 |
| --- | --- | --- |
| `0e34b4` | 正向分支的时域输入和目标地址 | 自己计算128点频谱，不使用原生频谱作输入 |
| `7ff7f4` | 乘加前的两路频谱、目标缓冲和比例 | 两路频谱必须找到自己的正向FFT生产者 |
| `70eeb0` | 逆变换结果、旧历史和当前输出缓冲 | 自己的累加结果经逆变换；自己的上一块历史 |
| `70ef6c` | 归一化输出和新历史 | 自己计算的重叠输出，与原生比较 |

末次乘加的结果通过逆变换输出核对；连续乘加之间还核对目标缓冲的完整128项。窗口中找不到计算生产者、历史不符合初始零状态、顺序不符或仍有未消费累加器时均失败，没有回退使用观察到的中间数组。

首次完成的采集在第129个输出块直接停止，留下两个已累加、未消费的缓冲。2049408项数值比较虽然一致，连接窗口仍判失败。最终捕获要求至少129块，并等到当前批次全部消费，实际到第131块结束；没有缩小窗口或放宽数值判据。

最终同次运行包括537次正向FFT、5208次乘加、131次逆变换和131次重叠输出：

| 比较内容 | float32项数 |
| --- | --- |
| 乘加A路计算频谱 | 666624 |
| 乘加B路计算频谱 | 666624 |
| 乘加前独立累加历史 | 666624 |
| 逆变换时域结果 | 16768 |
| 旧重叠历史、复制后的当前缓冲、最终输出和新历史 | 33536 |
| 合计 | 2050176 |

131块均含非零输出，8384个输出值中8375个非零，绝对峰值1.4405347108840942。输出是内部卷积信号，尚未经过最终音量和PCM量化。

## 线程调查和严格失败记录

本轮七次调试采集中，前五次因多线程硬件断点停止而未正常结束。观测点调整包括去掉逆向分支入口、保留正向专用分支；另外用独立进程的 `--multicore 0` 做过对照。REA确认该选项写入进程配置的 `multicore` 数值，`max`映射为2；它没有消除本次卷积后台线程，不能当作关闭全部线程的证明。

未调试的官方程序以 `--multicore 0` 渲染，PCM仍与原始参考逐字节同。后续捕获恢复原来的CLI参数，限定主线程后两次运行均正常退出，最终两次没有触发自动继续。实验中考虑过的额外配对继续规则没有实际触发，提交版本保留仅允许自有固定位置、最多三次且无回调错误的原有保护。

最终原生进程29823正常exit0，完整113152帧、48kHz、双声道24-bit PCM为：

`19481af4235d57e6db522290e2d90dd07fd8cf548c0264f549b1e3863422c84d`

与官方参考有148623个交错样本不同，最大整数差15089，首次差异frame4611，归一化RMS差8.383565726205929e-05。该变体与pass48相同，原因仍未确定；不能只凭断点时序现象断言音频差异的根因。七次调试尝试的严格音频通过数为零，整体审计保持失败。

## 负对照与剩余边界

六个一ULP负对照分别修改乘加A路比较目标、乘加前目标、逆变换结果目标、旧历史目标、输出目标和新历史目标，均exit1且恰好一项失败。删除首个乘加B路频谱的全部正向生产事件也立即失败。未消费窗口的失败报告另行保留。

时域输入、脉冲响应初始化及任务选择仍观察，完整卷积分区、尾部任务和CABN外层最终输出尚未完全独立计算。下一步恢复输入环、分区选择和输出块传输，并继续定位完整音频变体。完整琴槌接触力、弦反馈、制音毡耦合、全部模型/预设和浏览器声音等价性仍未完成，不进行最终合并或部署完成声明。
