# 自算击键力度接入声源与实际音轨（pass147）

2026-10-17。将 pass146 的事件表接入声源准备及连续声部计算。在显式运行条件下，用真实 MIDI 和模型/预设曲线生成力度，替代这条链中的新击键、旧声部、硬度和激励合并力度输入。30 条实际 WAV 独立读回共 1272576 个 float32 采样全部吻合。仍不是独立最终立体声或网页声音验收。

## 生产输入与绑定

新增 `scripts/pianoteq_note_on_velocity_source.mjs`：严格读取本例 format0/单轨/PPQ MIDI，支持 VLQ、连续 channel running status、meta/SysEx 跳过和结束校验，提取正力度 note-on。当前重建明确只覆盖五次 note69/velocity96，不能当作完整事件调度器。

力度源保存原始 MIDI、小型曲线输入及摘要；绑定器重新解析 MIDI、构造四表、前向生成管理器随机数，并核对预测与比较记录。计算不读取原生力度目标或旧报告的预测力度。后续声部随机状态也必须与同一组前向初始化一致。

保留显式条件：velocity/128、kind0、配置 seed0、事件随机化开启、全局曲线覆盖关闭、普通线性曲线模式、当前预设在 note69 的修形为零。以上运行条件本轮未新观察。输入存档仍为历史桥接，没有宣称新同次模型生成。

源表审计新增选项：

```
--event-velocity <actual-midi-path> velocity-over-128-seed-zero
```

该选项要求已有 decoded base/preset 与 forward manager 模式。15 处 before/两模式 weights 的力度都逐位比较；任何差异使 passed/compatible 为 false。原有 2160 项源表与 20 个随机状态词计数保持独立。

## 实际计算消费

源表准备使用自算力度计算前缀幅度混合与激励衰减。连续链在以下位置替换输入：

- before：newVelocity 改用本次 MIDI 事件的计算值。
- 重击：old.velocity 改用该旧声部此前已生成的力度。
- 两模式 weights：硬度及谱计算的 controls.velocity 改用计算值。
- 激励合并：沿既有 voice.newVelocity 输入使用本次计算值；两模式 postInputs 力度均比较。

原生目标只作相应边界比较。新增 29 项声部链力度比较；依赖元数据分别标明 note-on/old velocity 不再直接观察，同时继续标明声部选择、计数、部分初始历史和其它控制来自观察。分轨 manifest 自动继承新的来源说明。
