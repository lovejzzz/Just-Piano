# 真实重复击弦：随机振幅与模态历史更新（pass31）

本轮用自己编写的快、慢两组同键连击 MIDI，实际触发此前缺失的 `repeatFlag=1 && attenuation>0` 分支；没有通过写进程内存强行打开标志。每组5次击弦，第一击为普通路径、后4击为真实再击，涵盖延音踏板按下和松开。`pianoteq_write_repeat_fixture.py` 可逐字节重建两份原始刺激 MIDI。

快连击的实际历史混合量约为 .5943、.7925、.9177、.4974；慢连击约为 .001425、.1283、.2826、.0001112。后者覆盖历史强度 `min(3*attenuation,1)` 尚未饱和的分支。

## 原始模态振幅随机修正

`dsp/excitation-repeat.mjs` 的 `randomizeRepeatedExcitation` 复现 `695860..695940`。每个原始模态的每根弦消耗一次 xorshift128，追加模态跳过；即使原振幅为0也消耗随机数。

```
amount = f(attenuation * scale)
unit = float32(uint32Random / 2^32)
signed = f(f(unit+unit)-1)
factor = FMA(amount,signed,1)
amplitude[i] = f(amplitude[i]*factor)
```

原生约束 amount<.99，实际 scale=.1。两组各8条主次记录，各2000次数值或整数比较全部一致，包括修正后完整四表和最终随机状态。每组随机修正432个原始振幅；追加振幅保持不变。输入源表与首次随机状态仍捕获。

REA 精确指令证据 `ev_6ceb157c4211fdf63a32fad75dbf36d4c80d99f2464048d48f7399e0a50d2609` 确认 `69591c` 的因子 FMA，运算次序同时依据保留的 ARM64 指令及真实结果。

## 追加模态的连续历史

`updateRepeatedSupportHistory` 实现主路的 `695940..696024`。本批 A4有5个追加模态，历史向量第一次从空扩展为5项，新增项初始化1。随后每次再击使用上次**自己计算**的历史向量，不按次从捕获状态重置。

设 s=min(f(3*attenuation),1)，上下界分别为 FMA(s,lower-1,1)、FMA(upper-1,s,1)。本机 lower=.8、upper=1.4、randomScale=.6：

- 旧值≤下界：以下界为基数，指数为 f(s*randomScale*unit)。
- 旧值≥上界：以上界为基数，指数为 f(-s*randomScale*unit)。
- 中间旧值：以旧值为基数，指数为 f(s*randomScale*f(2*unit-1))。
- 更新值为 `clamp(f(base*exp2f(exponent)),lower,upper)`，每项仍消耗一个随机数。

接下来将更新后的历史、原始上下界转换为 `20*log10f` 的 dB。每项 dB 与最后一项 dB 按 blend=.4 混合，再根据该追加模态频率在 G+398 曲线中的值、历史强度及原始上下界做比例变换，最后以已恢复的标量 expf 转为增益并乘到该行全部弦振幅。其它三张表保持不变。实际曲线在0–2000Hz为0、4500Hz起为3.5，已覆盖非零频率整形。

REA 新证据 `ev_4f3d45c74a8d65e2f77dd0ea20f4c40b8b5fe86e1fe1b3105586ec80662fbae4` 确认 `695e5c` 的历史 dB 混合 FMA；公式每一步保留 ARM64 的单精度舍入次序，没有代数化简。

快、慢两组各4次连续历史更新，独立历史报告各1539项全部一致。再把上一步自己计算的随机修正源表及随机状态传入，桥接报告各3043项全部一致。两类报告有重复，不能相加当作独立样本。人为将一个最终历史值增加1单位float32的负例，准确报告一处差异并退出1。

exp2f、log10f 目前显式传入 `float32(2**x)`、`float32(Math.log10(x))` 候选。它们产生的本批完整历史与振幅逐位吻合，**不证明通用原生 exp2f/log10f 已移植**。标量 expf 和 xorshift128 使用已有恢复实现。音符、频率、曲线和每次再击前的随机种子仍有捕获依赖。

## 实际音频验证没有通过严格一致性

10次只读采集全部正常 exit0、无读取错误。每组另用原版执行3次完整48kHz/24-bit双声道离线渲染；未使用 Pedalboard，原版二进制哈希不变。

所有采集相对各组第一次原版渲染都存在 PCM 差异，最大为5–13个24-bit整数单位。因此本轮不能声称采集保持原版最终波形逐字节不变。

进一步重复原版本身也未得到固定输出：

| 原版对照 | 不同交错采样数 | 最大整数差 |
|---|---:|---:|
| 快连击第2次 vs 第1次 | 217037 | 28969 |
| 快连击第3次 vs 第1次 | 91657 | 7 |
| 慢连击第2次 vs 第1次 | 147323 | 11 |
| 慢连击第3次 vs 第1次 | 167410 | 9 |

明显的快连击异常从第14984帧开始，归一化差值 RMS约.0001281；原版初次与第3次的差值 RMS约1.09e-7。两份峰值均约.42765，但峰值一致不能证明波形等价。文件、完整日志和差异统计全部保留。原因尚未查明，不能归因于“只有舍入”或据此宽松通过最终声音判据。

## 当前边界

随机修正与主路历史更新已在真实快/慢连击中完成数值验证，并在这两段之间接通计算结果。它们尚未和此前整条谱生成、追加、合并以及声部连续渲染链合并为重复击弦的端到端自计算。单弦历史最多16项、历史长度变化、其它音符/模型/预设及系统数学函数通用性仍需验证；初始普通击弦的观察结果不替代这些要求。

浏览器当前音源也尚未接入完整研究链。本轮结构检查和 `npm test` 通过，完整声音复刻与合并条件未满足。
