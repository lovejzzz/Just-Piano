## 原指令中的完整中间步骤

`53f524..53f5a4` 的事件随机化，只有相应事件kind/索引/host开关及非零原始值等条件成立时取一次管理器随机数。无符号字按固定点2^-32转换为float32，乘float常量1/127，再经单独float加法合入。kind1的零值另有.5分支。

随后 `252000` 读取host+30/+48/+60/+78中按事件类型选择的查找表，要求129个float。对有限输入的普通分支：

```
u = f(clamp(value,0,1) * 128)
i = trunc(u)
t = f(u-i)
v = FMA(f(1-t), table[i], f(t*table[min(i+1,128)]))
```

kind0/1再乘127/128，kind1另设最低1/127，kind16使用-1下界，其余下界0，最终上界1。kind0原始值为零时直接返回，不进入插值。新 `dsp/manager-event-velocity.mjs` 只实现这些静态已恢复步骤，**必须显式提供129点表与事件条件**，没有默认MIDI映射或表生产器。

查找后 `7936f4..793738` 还可能用G+a4执行 `v + f(.3*a)*sin(pi*v)` 的double FMA修形，再转float。其生产者 `4ca334` 为A+ec8加A+ed0音高曲线并夹在[-1,1]；当前解码预设在note69的两项均为0，但未新增运行时分支观察。
