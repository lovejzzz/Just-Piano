# 复根到频率／衰减：第八轮运行验证及排序纠正

第七轮未采齐的输出链已在本轮补上：使用一个固定内部硬件断点，捕获同一次调用的复系数、复根、排序索引、频率和衰减。**32 组记录包含 18 组 N=3、14 组 N=2，共 82 个分量；164 个频率／衰减 double 输出全部逐位吻合。** NumPy 独立求根最大绝对误差 `2.3914935841127266e−15`，原程序复根的归一化多项式残差最大 `1.8806339946606975e−14`。该次渲染正常退出，PCM 与官方原版相同。

这验证局部复系数→求根→频率／衰减链，不等于恢复琴槌、琴弦和制音毡的全部接触计算。

## 数值闭合与排序纠正

复系数向量首项作为最高次系数，独立 `numpy.roots(c)` 与实际根接近；将系数反向作为负对照，32 组中的最小根集合误差也达到 `1.0388193254406521`。这支持第五轮恢复的系数方向。

对根 `z_j=u_j+i*v_j`，原指令先计算未舍入的 double 频率：

```text
F_j = abs(((center+center)*pi + u_j)/(2*pi))
key_j = fma(F_j, 1e-16, v_j)
order = indices sorted by key_j descending
floor = v_order[0] / floor_ratio
frequency[k] = double(float32(F_order[k]))
decay[k] = double(float32(max(v_order[k], floor)))
```

排序辅助函数 `1004cfac4`、N=3 路径 `1004d030c..` 的指令实际以衰减数组作为主项、频率乘 `1e−16` 作为附加项。常数位模式为 `0x3c9cd2b297d889bc`，即 double `1e−16`。**它不是按频率递增排序。** 独立重建的排序索引在全部 32 组中与原程序一致；其中仅 13 组的输出频率恰好递增。

首组 N=3 的实际根：

```text
(-0.5714401020299785, 0.6285553985708883)
( 0.3517252125129138, 0.07380625226714989)
(-0.2505524533729784, 0.013110835129321301)
```

该组 `center=349.056`、`floor_ratio=1000000`，索引 `[0,1,2]`；输出为：

```text
frequency = [348.9650573730469, 349.1119689941406, 349.01611328125]
decay     = [0.628555417060852, 0.07380624860525131, 0.01311083510518074]
```

频率并不递增。第五轮文档中“最低频率分量的 v 对全部衰减施加下界”的说法已更正为“排序首项”；不能继续据旧表述构建独立引擎。本轮没有主动覆盖下界钳制生效、相同 key、零系数剔除或 N<2 快路，因此不能把它们标成已运行验证。
