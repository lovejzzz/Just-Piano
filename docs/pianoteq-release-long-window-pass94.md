# 连续长窗口与十二模态尾部：pass94

本轮扩展 pass93 的同次采集与独立递推验证。它仍是特定 A4/Rattle 实验的内部三组缓冲验证，不是完整琴槌—琴弦—制音毡模型，也不是浏览器最终立体声音色验证。

## 可配置窗口与内核尾部

采集器通过 `PIANOTEQ_CONTINUOUS_BLOCKS` 在启动前指定 1..512 块，默认保持 8 块。重放读取相同元数据；旧捕获未保存该字段时仍按 8 块处理。输出、刷新及末尾完整性断言都使用同一窗口，缺失事件不补齐、不从目标重置递推状态。

REA/Ghidra 在不可变 ARM64 原件上取得 7c0bcc 的完整指令证据，记录 `ev_08a526dbd88d8b966b9192f1c66c8f7a40e3da72742e58c64d44bb964f59e5be`。7c0edc..ee4 的尾循环每次推进八个 float，并从四通道向量计数减二。因此十二模态余数执行两次八通道内核；它与单次十六通道内核的输出求和顺序不同。`renderModalVoiceBlock` 已按此顺序实现，仍要求完整的真实 padding 状态与边界检查。

## 已完成验证

A 次 64 块覆盖 4,096 帧、约 85.33 ms，205,703 项检查零差异，含 age512、2496、3776 三次删模态及之后的输出。该窗口没有触发十二模态尾部。原 8 块捕获回归通过；64 块基准的 110 项反向扰动全部被拒绝。

## 320块结果：输出通过，完整状态仍失败

D 次进程60154正常exit0，采集3350个包络、3304次复制、121次释放系数、320次刷新与320个完成输出。完整性断言通过，六个硬件点最终关闭。独立递推覆盖20480帧、约426.67 ms，执行90次删模态，28个组/块实际执行十二模态尾部。

744247项检查（743577个float32、650个double、20个uint32）中，**61440个完成输出采样全部逐位相同，但32个Q状态的正负零位不相同**，首次age8576/lane119，自算为+0、原生为−0。完整报告因此保持`passed=false`。没有忽略符号位、添加容差或把目标Q写回自己的状态；符号来源仍待恢复。不能把本次描述成全部状态通过。

原实现先在age13504拒绝releaseShape=1.2750000953674316。静态8638e8..3988确认该分支只覆盖逻辑模态：低于下限时`fma(release, shape, modalDecay)`；上下限之间，先以float32计算`x=(frequency-high)*(-1/max(high-low,1e-5))`，再依次`fma(shape-1,x*x,1)`与`fma(release,result,modalDecay)`；高频及padding保持先前基准。实现保持原float32/FMA顺序，需要显式的频率、逻辑lane标记和阈值，不推测缺省值。

补齐该分支后曾有92处位差：上述32个Q和60个归一化字段。后者源于gain=extraGain=0时原生8639b8直接跳过归一化并保留旧字段，而自算比较误用了0。现在保留自己上次计算的归一化状态，该60处消失；未从目标读取旧归一化值。原92处失败报告另存，没有删除。

重放失败诊断新增epoch、age、lane和float位模式，明确区分数值打印相同的正负零。长窗口的反向测试尚不能以这个失败基准证明有效，未计入已通过的110项。

## 保留的失败

B 次进程57453正常退出，取得384个输出块，但只有382个刷新观测，缺失age24512和24576，完整性断言失败，`complete=false`。其中有69个刷新后的布局含十二模态余数，首次age5568；这只是覆盖观测，不能把不完整捕获当作重放通过。没有裁去末尾改称384块验证成功。原程序是否跳过刷新或存在未覆盖路径尚未查清。

C 次进程60028在硬件停止后，外层非交互会话的输入关闭，进程已不存在；该次没有正常完成证据，不计入通过。D 次使用保留交互输入的独立会话。

## 完整音频限制

A、B、D 的原生 WAV 均为148224帧、双声道24-bit/48kHz，正常退出。与既有参考的完整 PCM 严格比较均失败：A 有152210个不同交错采样，最大整数差4858；B 有114397个，最大整数差14；D 有138532个，最大整数差11。不得将这些原生 WAV 称为独立 JS 生成的音频，也不得以局部内部样本通过代替整段 PCM 一致。

预权重源表、部分模型/控制输入、初始随机种子、初始起音旋转与滤波系数仍有观察输入；double pow 仍须显式启用候选。当前网页引擎尚未接入这条完整链，全部预设、接触力/弦反馈/制音毡闭环和最终立体声仍未完成。
