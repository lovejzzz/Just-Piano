# pass66：全局模态动态系数刷新公式

将pass65的“50张更新表作为输入”推进到原生模态字段与衰减值。889次写入的四个参数由自己计算，持续更新三组内核的系数和状态。128块3032648项检查逐位一致；完整原生PCM与官方参考相同。仍没有把这些局部恢复宣称为完整声源等价。

## 从真实调用者恢复公式

虚表 `bc9a08+8` 指向系数写入 `798084`，实际889次动态调用全部来自 `3ca148` 的返回地址 `3ca328`。三个内核位于该生产者对象的c8/d0/d8；每条80字节模态记录的30/34字段选择内核和内核内模态编号，捕获与重放逐次核对归属。

令r为模态记录，dt为生产者38字段，D为r20的当前衰减（这里的20等偏移均为十六进制）。[实现](../dsp/global-modal-recurrence.mjs) 按原生顺序计算：

```
t = float32(-float32(dt * D))
s = float32(t + 1)
u = float32(r18 * s)
v = float32(r14 * s)
B0 = r10
B1 = fma32(r0c, v, -float32(r10 * u))
C1 = float32(-2 * u)
C2 = float32(float32(t + t) + 1)
```

写入器按每四个模态交错排列，保存 `[B0, B1, -C1, -C2]`；后两项的负号对应pass65递推的A1/A2。没有用反编译表达式任意重排乘法或以普通乘加代替FMA。

## 连续验证与输入边界

[采集器](../scripts/pianoteq_capture_global_coefficient_writes.py) 首次全局入口取得三个内核的初始表，再启用固定写入点。四个逻辑硬件点同时最多四个启用；写入、模态入口及返回均为固定地址，未注入调用、写目标内存或使用Pedalboard。

[重放器](../scripts/pianoteq_replay_global_coefficient_writes.mjs) 只用初始表初始化一次。每次从生产者字段计算四个参数，原生参数仅作比较目标；随后的整张版本表也只作比较，不替换自己的系数。自己的连续递推状态、计数器和上一输入不被原生末态重置。

889次写入分布在block14和61–109。早期每块27个模态，逐渐减少到最后8个；均写第一个内核。完整表检查1507328项，写前旧系数3556项，计算参数3556项，既有连续递推1518208项，合计3032648项，零差异。114个输出块非零，三个内核各25次周期清零。

当前仍观察r0c/r10/r14/r18静态模态字段、dt和已选定/限速的D。按键关联权重、踏板控制选择、D的生成及dirty队列交换尚未移植；不能称完整动态系数生产已经恢复。mono输入、处理前已有目标、全局驱动及空间返回也仍有边界。本轮没有生成贯穿这些新计算的独立WAV，完整音频审计仅证明本次原生捕获未改变参考输出。
