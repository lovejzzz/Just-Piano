# 自算声部输出接入主线程延迟：pass98

本轮将pass97的同次自算工作线程缓冲接到主线程3e229c延迟处理。它复用已恢复的延迟/增益内核，新增真实输入桥接与跨线程时钟验证，不把观察到的消费缓冲当作DSP输入。端点仍位于释放附加信号、后段增益、空间网络与最终混音之前。

## 六个活动点的分阶段采集

`PIANOTEQ_CONSUMER_DELAY=1`隐含全声部与调度采集模式。初始化阶段仍有六个硬件点；第五次最终初始化完成且10路权重全部记录后，删除已不再需要的权重观察点，新增460908消费输出观察点。转换时当场核对目标登记数、活动数与hardware属性均为6，保存旧/新断点ID、地址及阶段计数。

保留4604d4读取消费前延迟状态和原有释放复制，避免把更晚时刻的工作线程包络误当作复制时刻的值。460908位于三个3e229c调用之后、0fbb44释放附加处理之前。源工作线程缓冲按`epoch + 消费年龄H+6c`关联，不能用可能提前数块的当前工作线程计数器替代。

前四个声部的消费输出观察从各自年龄16192、10496、8000、6016开始，第五个声部从0开始。初始化前缀仍从自己的工作线程源推进延迟历史；这些较早输出没有被冒称为直接观察过。每声部的比较起止年龄、计算块数、消费前状态观测数与消费后输出观测数分别保存在`consumerCoverage`中。

## 延迟历史与观察边界

每声部第一次4604d4必须为年龄0。读取一次长度、写入增益、干增益、平滑目标、乘子及剩余步数，验证逻辑空初态后以自己的零环形缓冲建立状态。当前三组初态均为长度432、writeGain=0.04775214195251465、dryGain=1、target=0.9522478580474854、multiplier=0.9999898076057434、remaining=4800。

后续每个输入块来自本次独立算出的工作线程组缓冲；`renderVoiceDelay`持续更新自己的历史。消费前/后原生增益、计数器和周期性完整环形缓冲仅用于比较，没有回填。消费前状态观察之间存在少量缺口，仍从自己的连续源计算中间块，而不是填造原生目标。消费后输出观察则要求每声部的已观察后缀严格连续，每64采样一块，末尾必须覆盖最后一次消费前观察；第五声部必须从0开始。

当前要求worker spread=1、消费前重分配旁路，mute保持初始状态；活动重分配、mute切换及未知平滑器重播种仍明确拒绝。延迟初始控制量是观察输入，尚未声明其完整GUI参数生产算法已恢复。

## 负向测试与回归

12项扰动全部被拒绝，均返回非零退出码：

- 修改延迟后一个输出样本、一个块后dryGain、一个块前dryGain、一个块后环形缓冲样本，分别恰好1项差异；四份报告中的全部自算消费输出哈希与未扰动基准一致。
- 修改初始writeGain产生33508项差异，自算输出哈希确实改变，证明该值是输入而非仅比较项。
- 非零初始环形缓冲、缺少阶段转换、活动点数改为7、删除某声部全部消费输出、删除第五声部第一个消费前观察、删除后缀中间一个输出块、删除第五声部首个输出块，均被结构或连续性检查拒绝。非法活动点仅修改离线JSON，没有新增原生断点。

私有测试脚本、各例输入哈希、失败报告及计算输出哈希保留在`pass98-negative-consumer.py`、`pass98-negative-consumer-results.json`和`pass98-negative-consumer/`。pass96旧调度窗口、pass97全声部工作线程捕获回归均通过且零差异；Node语法、Python AST和git差异空白检查通过。

## 剩余范围

本轮没有改变网页声音引擎。延迟初始控制量、上游模型表、部分调度/初始化输入仍观察；后段0fbb44释放附加信号、终端增益、空间网络、全局反馈及混响尚未接到本轮连续链。完整琴槌接触力、弦反馈、制音毡耦合、所有参数生产与全部预设仍未完成。报告明确保留`fullConsumerTailImplemented=false`和`finalStereoAudioVerified=false`。
