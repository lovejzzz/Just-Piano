# Pianoteq 琴槌硬度 × 力度交叉音频实验（pass 4）

日期：2026-10-15。官方 Pianoteq standalone 9.2.5/20260909，使用上一轮已在全新进程验证保存值的 FXP；没有重复设备配置或参数保存，没有使用 Pedalboard 或其它插件宿主。

## 设计和证据

六个单变量预设：`hammer_hardness_piano`、`hammer_hardness_mezzo`、`hammer_hardness_forte` 各 normalized 0.25/0.75。各自与 NY Steinway D Mix 基线在 MIDI 力度 32、64、96、127 交叉比较，总计 24 个干预 + 4 个基线。

统一 A4/MIDI 69，0.5 秒起音、5.5 秒松键，10 秒 MIDI，48 kHz 双声道 24-bit PCM，dither OFF，不归一化。九份先前同条件 WAV 直接复用，逐字节核对对应 MIDI 一致；另 19 份通过官方 CLI 新导出，全部正常退出 0。没有播放扬声器或启动实时 GUI。

证据位于 `~/.local/share/just-piano-analysis/audio-pass4/`：`results.json` 含每个样本来源、新/旧完整命令、FXP/WAV SHA-256、退出码、全量测量和基线差分；新渲染有各自日志；`experiment.py` 是本轮实际执行脚本副本；`sha256-manifest.json` 是证据哈希清单。复用样本原日志和已验证参数保留于 `audio-pass3/verified/`。

谱重心测量：0.55–0.95 秒双声道平均信号、Hann 窗、FFT 功率权重、100–12000 Hz。起音能量用 0.5–0.7 秒双声道 RMS 表示。首秒 PCM 对照使用 WAV 的 0–1 秒，包含起音；不把松键后低幅机械声的随机差异混入该等同性判断。

## 单变量影响

下表每格为相对同力度基线的 **谱重心差 Hz / 起音 RMS 差 dB**。`相同` 表示首秒 PCM 逐样本完全一致，不只是显示数值四舍五入到零。

| 目标参数 / normalized | 力度 32 | 力度 64 | 力度 96 | 力度 127 |
|---|---:|---:|---:|---:|
| piano / 0.25 | -56.13 / +0.191 | -24.12 / +0.040 | 相同 | 相同 |
| piano / 0.75 | +195.21 / -0.233 | +66.11 / -0.068 | 相同 | 相同 |
| mezzo / 0.25 | 相同 | -76.82 / +0.165 | -9.24 / +0.003 | 相同 |
| mezzo / 0.75 | 相同 | +25.80 / -0.028 | +3.12 / -0.002 | 相同 |
| forte / 0.25 | 相同 | 相同 | -86.80 / +0.083 | -114.36 / +0.069 |
| forte / 0.75 | 相同 | 相同 | +8.34 / -0.005 | +13.25 / -0.006 |

这组干预揭示了实际音频中的分区与重叠：

- Piano 硬度在本次力度 32、64 有作用；96、127 首秒 PCM 与基线相同。
- Mezzo 硬度在 64、96 有作用；32、127 首秒 PCM 与基线相同。
- Forte 硬度在 96、127 有作用；32、64 首秒 PCM 与基线相同。
- 力度 64 同时受 Piano/Mezzo 控制，96 同时受 Mezzo/Forte 控制。三个参数不是各自只在单个离散力度值生效。

力度 32 的 Piano 高值使重心增加约 195 Hz，但起音 RMS 下降约 0.23 dB；Forte 低值在力度 127 使重心减少约 114 Hz，而起音 RMS 只增约 0.07 dB。因此当前声学结果不能用整体增益变化概括，也不应把峰值、RMS 或谱重心中的任何一个等同于硬度本身。

## 结论边界

这是由已验证单变量预设、固定 MIDI 和真实 PCM 得出的力度相关因果证据，强于仅看参数名称。四个力度点不足以求出精确交界、插值函数、速度到琴槌初速度映射或接触力方程；也没有覆盖其它音高、乐器预设、每键硬度和完整弦耦合。谱重心并不一定随全部参数单调变化。起音混音仍含拾音与效果，不能单独归因于某一内部振动模态。完整公式需与 REA 数据流及更精细的采样对照继续核查。

## 补充：整数力度边界二分

沿用三个硬度 normalized 0.75 的已验证 FXP，以同力度基线的首秒 24-bit PCM **精确字节相同/不同**为判据，没有采用差分阈值。按“每个硬度参数在所搜索区间内只有一个连续支撑区间”的假设做整数二分，再检查边界及相邻 ±1。新目录 `audio-pass4-boundaries/` 保留 37 份新 CLI WAV/命令/日志、复用来源、29 次参数×力度对照、首秒 PCM 哈希、差异字节数与二分结果。全部新渲染正常退出 0。

| 搜索目标 | 二分初始区间 | 邻点验证 | 定位到的转换 |
|---|---|---|---|
| Piano 最后影响点 | 64–96 | 70 有、71 有、72 无 | 71 → 72 |
| Mezzo 首次影响点 | 32–64 | 44 无、45 有、46 有 | 44 → 45 |
| Mezzo 最后影响点 | 96–127 | 97 有、98 有、99 无 | 98 → 99 |
| Forte 首次影响点 | 64–96 | 71 无、72 有、73 有 | 71 → 72 |

“有/无”限定为本机、该音高/预设、该参数高值、首秒窗口中有/无可表示的 24-bit PCM 差异。它不是任意精度内部系数的零判定，也不是完整 MIDI 1–127 全点扫描。实际采样的力度为：

- piano：64（有）, 68（有）, 70（有）, 71（有）, 72（无）, 80（无）, 96（无）。
- mezzo：32（无）, 40（无）, 44（无）, 45（有）, 46（有）, 48（有）, 64（有）, 96（有）, 97（有）, 98（有）, 99（无）, 103（无）, 111（无）, 127（无）。
- forte：64（无）, 68（无）, 70（无）, 71（无）, 72（有）, 73（有）, 80（有）, 96（有）。

在连续区间假设下，这些结果支持 Piano/Mezzo 的重叠作用区跨越部分 45–71 力度，以及 Mezzo/Forte 的重叠作用区跨越部分 72–98 力度。但未采点不能标记为已验证，边界以外也没有在每个整数力度穷尽排除非单调情况。这些整数转换仍不能直接证明内部以原始 MIDI 力度作分段：内部可能先经过力度曲线、初速度映射或其它变换。
