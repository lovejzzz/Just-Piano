# pass78：源模型初始化接入同次连续包络与再击

将pass77的初始化来源与pass76的连续状态放进**同一次原生运行**。初始化的自算多项式、速率、增益和步长持续传给系数刷新、包络、复制表和再击控制，34283项比较逐位相同。28项负对照全部拒绝。**完整PCM仍失败，尚无独立完整声源WAV或浏览器声音等价证明。**

## 消除哪些观察输入

[重放器](../scripts/pianoteq_replay_initialized_envelope_chain.mjs)复用已有`initializeReleaseModel`、`releaseCoefficients`、`ReleaseProgressEnvelope`和`repeatedStrikeControl`，但不再从每次系数刷新读取多项式/模型标量作为计算输入：

1. 在新声部登记后，读取一次实际初始化来源P、G、R及选中衰减行，独立生成5个多项式系数、rateScale/gainScale/cubicScale/cubicGainScale/timestep。
2. 保存自己的模型结果。原生初始化目标、后续系数刷新中的模型字段都只比较，不刷新自己的模型。
3. 每次实际系数刷新用自己的模型和观察到的x/u/flag计算D/rate/gain，保存生成编号。原生结果只比较。
4. 包络使用自己的D、自己的c0作为baseDuration、自己的timestep。原生baseDuration/timestep/D只比较。
5. 独立累积包络位置与样本计数，在实际复制事件中提交自己的位置；下一击旧释放值从自己的复制表读取，驱动再击控制。

自己的持键冷态包络与D/rate/gain初值仍为0；原生更新前/后位置及计数用于验证，不用于重置。每个模态对象必须等于已登记声部+168；初始化只允许一次，必须早于包络/系数消费。系数生成编号与包络逐块绑定，不把声部初始化线程等同于工作线程。

本轮仍观察初始化的上游配置/矩阵、x/u/flag、块长、刷新时机、旧声部选择/计数/力度/历史。**只是减少了边界，不是完全消除所有原生输入。** rate/gain目前比较到生产结果，没有借此声称它们已在本轮独立推进完整声部模态输出。
