# pass65：全局反馈的三组连续模态递推

把全局反馈生产者的实际虚调用绑定到 `657dfc → 667fc4`，恢复三个内核的数值递推、输入乘加顺序、分批求和和周期清零。128个连续64帧块共1518208项检查逐位一致。初始状态只设置一次为零，随后状态全部由自己的计算推进。

## 已恢复的计算

[实现](../dsp/global-modal-recurrence.mjs) 中三个内核的逻辑模态数为2044、122、764，SIMD补齐后为2048、128、768；vectorCount分别512、32、192。共有5888个状态float和11776个系数float。

每个SIMD向量存四个模态。系数排列为B0、B1、A1、A2各四lane，状态排列为older四lane、newer四lane。每个采样计算：

```
y = B0 * current + B1 * previous + A1 * newer + A2 * older
older = newer
newer = y
```

这只是代数表达式，实际实现保留原生float32和FMA次序。输入两项的次序随块内采样和批内向量变化：

| sample % 4 | 批内vector 0 | 批内vector 1–3 |
| --- | --- | --- |
| 0 | 先舍入B0×current，再FMA另一项 | 先舍入B1×previous，再FMA另一项 |
| 1、3 | current先 | current先 |
| 2 | previous先 | previous先 |

随后依次FMA(newer,A1,y)、FMA(older,A2,y)。每批四个向量按左结合float32累加各lane，再累加到块scratch。最终水平和为 `(lane0+lane2)+(lane1+lane3)`，加到已有mono目标。三个内核按实际派发顺序依次叠加。

每五次调用前按绝对阈值（float32位型 `0x219392ef`）把小状态清为正零；三个内核各观察并计算了25次周期清零。上一块最后输入作为下一块previousInput。当前实现明确只支持本次验证的零初态、启用状态与vectorCount为四的倍数的分支。

## 动态系数仍是输入边界

第一个内核在block14及block61–109更新，共50次；其余两个系数表稳定。采集器按小端float位型计算SHA-256并保存版本，重放器核对版本身份，再更新自己的系数表而不重置状态。

大部分更新涉及27个模态的B1、A1、A2，共81项，B0不变；末次更新只涉及8个模态。此前“整段系数不变”的假设在block14被严格拒绝。该现象尚不足以推出制音力公式或GUI参数映射，系数生产者仍待恢复。

本轮仍读取原生三个mono输入、处理前已有mono目标及动态系数表。原生前后状态仅作核对目标，后状态不进入DSP。完整驱动、队列源、空间返回与琴槌—弦—毡接触方程没有因此闭合，也没有接入网页。

## 捕获、失败与严格验证

[采集器](../scripts/pianoteq_capture_global_recurrence.py) 只在主线程使用四个固定硬件地址：`6c2ac4`、`829d48`、`804a14`、`6c2bf8`。没有目标内存写入、注入调用或完整性补丁；原应用保持不变。

早期尝试分别遇到：8192系数word超过既有单次读取保护、未初始化驱动scratch中的NaN不能严格JSON解析、固定系数假设不成立。失败目录和执行脚本均私有保留。修正采用4096word分块读取，未放宽读取上限；无计算用途的scratch按uint32原始位保存，正式JSON禁止NaN；系数采用完整版本身份核验。每次重试均先确认旧原生进程终止。

正式v4窗口128块完整，原生78747正常exit0：[重放器](../scripts/pianoteq_replay_global_recurrence.mjs) 检查1516288项float32和1920项计数/标量，合计1518208项，零差异。114块mono输出非零。独立音频审计确认同次原生完整113152帧、48kHz双声道24-bit PCM与官方参考逐字节相同：

```
1907f854d5c427908038ee9629a5c8997facbb71242e30b94874fc0553a4c9d6
```

本轮没有生成由这三个新内核贯穿全链的独立WAV；以上完整音频只验证捕获运行与参考一致，不能当作全引擎等价证明。pass64的完整计算WAV仍以较后反馈为输入边界。

12项负对照全部拒绝：输入、前状态目标、后状态目标、previousInput目标、输出目标、内部一致但改值的系数版本、过时版本、缺失版本、计数器、派发顺序、缺失结果和不完整窗口。前/后状态及输出目标的一ULP扰动各恰好一处差异；输入扰动521495处、系数扰动4350处、过时版本10263处、派发顺序551241处。统一采用current-first的简化公式产生1269458项差异，单独保留为失败诊断。
