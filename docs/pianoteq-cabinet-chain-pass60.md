# pass60：完整头部、尾部与外层三通道返回

新增 [CabinetConvolution64](../dsp/cabinet-convolution.mjs)，连续400块计算64帧头部、512帧尾部队列和外层相加。完整76800个三通道返回样本与原生逐位同，合计606336项检查通过；完整原生PCM同基准。

## 独立处理器

构造时仅使用本次初始化配置和IR时域源，自行生成两组IR频谱。每个块以九行64帧源和三行既有目标为输入，按已验证的单位输入增益、相加模式执行：

```
head = compute64FrameBank(source)
headOutput = f32(existingDestination + head)
tail = queued512FrameBank.process64(source)
output = f32(headOutput + tail)
```

头部和尾部历史均从零开始自行推进，不把实际头部、实际队列尾部或返回样本写回计算状态。前14个静音块也由独立处理器计算；它没有尝试复刻原生跳过这些空调用的CPU调度，数值仍逐位相同。

既有目标不是由九行源猜测出来的，仍在函数入口观察，下一步需要沿全局输出的前置路由和混合追溯其来源。非单位输入增益、复制模式、活动斜坡及其它配置尚未得到本轮覆盖。

## 同次观测

[采集器](../scripts/pianoteq_capture_cabinet_chain.py) 全部断点限定主线程，使用初始化时域复制 `2a4334`、外层入口 `0ef37c`、队列点 `0ef75c`、返回前 `0eff54` 四个硬件点。第一个外层入口捕获实际持有的头/尾节点配置，绑定各非空IR对象的时域源并独立补零，再关闭初始化点。

头部144个非空IR分区、尾部121个，共265个分区，两个银行初始化输入环与历史均要求为空/零。本次所有绑定来自同一运行，不借用旧捕获的IR或计划。

[重放器](../scripts/pianoteq_replay_cabinet_chain.mjs) 分别检查入口源在单位增益后未变、计算的头部相加结果、计算的尾部消费切片和外层实际返回。主线程块序号是外层局部计数；本轮没有末级PCM断点，不宣称其局部帧号已独立校准到WAV绝对帧号。

## 实际音频与负对照

原生进程61695正常exit0，没有受限继续。完整113152帧、48kHz、双声道24-bit PCM与官方参考逐字节相同，PCM SHA-256为 `1907f854d5c427908038ee9629a5c8997facbb71242e30b94874fc0553a4c9d6`。这验证采集运行音频符合基准；WAV仍由原生程序生成，独立实现本轮输出的是上述三通道内部窗口。

16个负对照全部拒绝：入口源、既有目标、增益后源、头部目标、尾部目标、最终返回目标、头/尾IR时域源、头/尾IR频谱目标、模式、增益、消费位置、帧号、缺失队列阶段及不完整窗口。四种中间/返回目标和两种IR频谱目标的一ULP扰动各产生一项差异；既有目标增加0.125影响头部相加与外层返回各一项；入口源和头/尾IR时域源扰动分别产生16929、47067、34694项差异。`npm test`通过。

尚未恢复既有目标的完整生产链、IR时域生产算法、完整琴槌—弦—制音毡耦合、全部模型与预设和网页完整等价性。网页未接入本轮研究实现，未最终合并或部署。
