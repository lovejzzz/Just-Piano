# pass61：全局路由、支路相加与完整卷积连接

从同次观测的两行全局路由输入和三行支路开始，自行维护延迟缓存、读出三行并相加，将计算结果送入已恢复的完整卷积。400块的实际卷积前目标和外层返回均逐位一致，共298736项检查通过；完整原生PCM同基准。

## 移除直接的既有目标输入

[GlobalRoutedMix64](../dsp/global-routed-mix.mjs) 复用已验证的路由缓存实现，从逻辑空缓存开始，不读取原生缓存样本来补充历史。三条路由是输入0到行0、输入1到行1、输入0到行2；按实际延迟和增益表逐块写入并读出，再以float32与独立三行支路相加。

[重放器](../scripts/pianoteq_replay_routed_cabinet.mjs) 只把上述计算结果传给卷积的既有目标参数。外层入口实际目标仅作为比较值，没有用它重新初始化或修正状态。头部和尾部仍从同次IR时域初始化独立生成频谱并持续计算。

本次行屏蔽开关关闭、三行标志均为7。汇编在启用行屏蔽时按bit2决定是否保留目标行，模块保留该计算分支；本轮动态证据只覆盖关闭状态，不把该分支称为已经验证。

## 同次四点采集

[捕获器](../scripts/pianoteq_capture_routed_cabinet.py) 使用初始化复制 `2a4334`、全局路由调用前 `6c2fd4`、卷积入口 `0ef37c` 和外层返回前 `0eff54`，全部限定主线程。路由点从当前寄存器绑定真实R/S对象，读取路由输入、独立支路、表和缓存元数据；每块核对自行推进后的缓存读头/标志与实际下一块状态。

初始化IR、路由种子和卷积数据来自同一运行。未借用旧运行的地址、音频偏移或IR数据。实际目标只是核对点，缓存实际数据、卷积实际中间输出都不作为计算种子。

## 实际音频与负对照

原生进程63329正常exit0。初始化时在已设置的复制硬件点处暂停一次，既定保护只继续该已知地址，之后采集完整并正常退出；没有对未知异常地址放开继续。

完整113152帧、48kHz、双声道24-bit PCM与参考逐字节相同，PCM SHA-256为 `1907f854d5c427908038ee9629a5c8997facbb71242e30b94874fc0553a4c9d6`。本次局部块号没有独立校准到WAV绝对帧，WAV仍由原生程序生成。
