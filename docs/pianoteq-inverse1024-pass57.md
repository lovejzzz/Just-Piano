# pass57：1024点逆变换与512帧归一化、重叠相加

固定1024点实数逆变换已独立计算，139次非空变换与原生输出逐位同；连同5次空输出和三路历史推进，共364805项检查通过。完整原生PCM同官方基准。工作频谱仍由原生积累，整个512帧尾部卷积尚未独立计算。

## 计算

[逆变换实现](../dsp/real-fft-inverse.mjs) 将既有实数预组合扩展至1024点，尾端特殊值写到1020到1023，随后四级逆radix-4：

```
(ido,l1,waOffset) = (64,1,0), (16,4,192), (4,16,240), (1,64,252)
```

系数来自此前恢复的生成器，实际核心和最终逆输出均不从目标数据补入。[归一化及重叠相加](../dsp/convolution-overlap.mjs) 对前512帧以 `fma32(inverse[i],1/1024,previousTail[i])` 求输出，后512帧以float32乘1/1024保存为下一历史。空输出直接取旧历史并将历史清零；三路初始历史必须为零。

## 找准频谱边界

REA/Ghidra本轮重新查看逆核心 `3af4f4`、调度器 `7ff67c` 和输出包装 `72940c`。证据ID分别为：

- `ev_528b939493489ba87146f5f912b141d4ab71189f1b4957726ea33a60364bff0b`
- `ev_a548acb764409a292836430a17ac4d0efc4e86b03b6d0ae059035bdd41468325`
- `ev_91218d33651157ac23dae6b4d01498c0ea87a94fa13c7a38d5ad62d674526917`

调度器的kind=2命令已调用逆变换；之后节点调用的 `72940c` 是输出/历史处理。因此在节点输出虚调用前读取的FFT缓冲区已是content=2的时间数据，不能再当频谱送进逆变换。先前错误边界的81次诊断有206336项差异，原始数据和失败报告保留，未据此修改算法去拟合时间样本。

[最终采集器](../scripts/pianoteq_capture_inverse1024.py) 使用三个硬件点：

1. 调度器调用的逆包装入口 `22aaac`，读取content=0的积累频谱与旧历史，按银行512帧、九输入和工作线程过滤。
2. 节点在调度器返回后的 `7ccd48`，保存此刻完成的原始逆输出。
3. 末级PCM点，建立全局帧位置与WAV编码对应。

重叠相加后的输出和历史在同一对象下一次逆包装入口读取；当前频域积累会覆盖FFT缓冲区，但没有覆盖独立的输出和历史存储。原始逆输出已在第2点保存，避免把下一代频谱误认作上一代逆输出。48组、每组三路共144项完整配对后结束，最后一组在下一次包装入口完成观测。

[重放器](../scripts/pianoteq_replay_inverse1024.mjs) 按对象保存自行计算的历史。原生旧历史仅核对，不作为下一次计算种子；频谱、原始逆输出、归一化输出与历史的观测阶段分别处理。

## 中断采集与负对照

初始化主线程也会执行512帧节点，首个未过滤版本触发线程断言，未产生有效窗口。修正线程过滤后的相邻虚调用点在81次后停止。改读保留结果的一次采集完成130次，但它的入口仍是已经完成逆变换的时间数据，不作为独立逆FFT证明。

移到调度器间接调用指令 `7ff818` 后，124次逆变换与重叠相加的326656项数值全部一致，但进程停在该调用目标 `22aaac`，窗口未完成，因此仍不通过。最终直接在包装入口设置固定断点，避免使用间接调用指令作为观测点，获得完整窗口；期间一次在已设置的 `22aaac` 点异常暂停，保护逻辑只继续这个已知地址，之后正常exit0。未对未知异常地址放开继续。

12个有效负对照全部拒绝：频谱增加0.125并转float32、原始逆值、归一化输出、保存历史、旧历史、有效系数、通道、时钟、内容类型、分解因子、缺失返回和不完整窗口。大频谱扰动导致3066项差异；原始逆值/输出/历史/有效系数的一ULP目标扰动各恰好一项差异。

另一个频谱输入的一ULP探针被后续舍入消掉，最终所有比较值仍相同，报告保留为无影响探针，未列入已拒绝负对照。float32输出核对不能保证检出所有数学上不影响输出的输入改动。
