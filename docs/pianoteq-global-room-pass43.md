# pass43：全局空 EQ、房间干声增益及后段接通

补齐pass42前置处理中的空EQ与当前房间分支。默认和width25各160个64样本块，四次正式捕获共510720项逐位同，原生完整PCM均同各自官方参考。房间计算结果已接入pass42的两声道路由和末级音量；两个10240帧PCM前缀继续逐字节相同。

更早的 `CABN` 卷积分支仍观察输入，房间增益初始化仍读取，网页未接入本批代码，完整模型未复刻。后段接通验证重用pass42原生捕获，不是新执行的整条独立声源。

## 空EQ的初始化与实际输出

[全局滤波捕获器](../scripts/pianoteq_capture_global_filters.py) 在全局输出返回、`660974` 的固定调用前后、后续通道滤波返回处设四个只读硬件点。当前三行均无滤波节，SIMD表与历史均为空。首块 `updating=1`、缓存gain=0，但实际平滑状态为 `[1,1,1,0]`，`364a18 → 84df2c` 读取当前值1并清除更新标志；以后的gain一直为1。实现从首块状态自行初始化，没有逐块读取后续实际gain作更新。

[settled-global-processing.mjs](../dsp/settled-global-processing.mjs) 和 [全局重放器](../scripts/pianoteq_replay_global_filters.mjs) 计算该路径，并核对后续 `2d60f4` 在本窗口不改变矩阵。每场景96960项包括pass41计算边界30720、滤波输出30720、后续旁路矩阵30720及4800个状态检查。滤波前信号已经包含尚未恢复的卷积分支，报告明确 `cabinetMixInputStillObserved=true`。

## 关闭混响湿信号后仍保留的干声系数

`45c1f4 → 270ce8` 当前没有卷积对象、外部混响源或空间tap，湿scratch由原生明确清零。三行干声系数固定为：

| 行 | dry gain | wet gain |
| --- | --- | --- |
| 0 | 0.5233637690544128 | 0 |
| 1 | 0.42480674386024475 | 0 |
| 2 | 2.579881429672241 | 0 |

没有活动斜坡。`15dad8` 先按行乘干声系数；`16be40` 对零wet gain直接跳过，保留浮点符号零。实现遵守这个跳过条件，不把零增益路径替换成无条件FMA。非零湿系数的加法分支虽有静态顺序，本轮没有动态覆盖活跃混响、空间tap或斜坡，重放器拒绝相应状态。

[房间捕获器](../scripts/pianoteq_capture_room_mix.py) 观察FX前后、最终干湿混合前和外层返回；[房间重放器](../scripts/pianoteq_replay_room_mix.mjs) 输入来自另一份已验证的全局滤波计算报告，湿scratch独立生成为零，系数只取第一块种子并检查后续不变。每场景158400项覆盖输入、FX在本窗口不变、房间输入、清零湿scratch、返回矩阵以及系数/状态。当前窗口外层AntiClick没有改变计算结果，这不代表已实现其活动状态。

[输出路由重放器](../scripts/pianoteq_replay_output_routing.mjs) 新增 `--processing-report`，直接消费算出的房间输出，不再把路由前的三行实际样本当作输入。每场景194560项通过，接上末级音量各42240项通过；每组10240帧PCM前缀均无差异。这些连接检查重用pass42的路由/音量原生捕获，未覆盖完整WAV或其它音符。

## 尚未恢复的 CABN 卷积与失败记录

最初将全局输出直接与辅助矩阵相加，默认30720项中有27575项不同，严格失败保留。实际在相加前还有启用的 `3319ac`、标签 `CABN` 的分支；REA继续进入 `0ef37c`，其内部涉及 `mtconvolver.cc`。卷积核、分块历史、源矩阵与卷积加法仍待恢复，没有把名字或调用关系当作计算完成。

本轮共七次原生尝试，四次正式成功，三次失败：首次滤波捕获未处理空数组，回调断言后窗口不完整；第二次在共享 `660974` 硬件点处出现未预期 `EXC_BREAKPOINT`；第一次width25房间捕获也在自设硬件点处停止。三次均无正常原生exit0与完整PCM，不计通过。随后把滤波观察移到固定调用点，并增加最多三次、仅对本捕获已知硬件点且无回调错误的停止恢复；最终width25新捕获正常退出0，实际上没有触发恢复。停止原因未证实，未修改程序指令或系统安全设置。全部尝试汇总 `pass43-native-attempts.json` 仍为严格失败，最终正式场景审计另列。

七个负对照均exit1：滤波输出、后续旁路输出、房间输出、湿scratch、FX比较目标各改一ULP，分别恰好一项失败；声明活动卷积或删除阶段也失败。私有目录 `~/.local/share/just-piano-analysis/` 保留原始失败日志、`pass43-naive-aux-sum-diagnostic.json`、负对照和最终审计。`pass43-preliminary-audit.json` 保留第一次width25失败；`pass43-final-audit.json` 对应当前通过的正式捕获。REA导出285条累计证据及快照并关闭，记录数不代表覆盖率。
