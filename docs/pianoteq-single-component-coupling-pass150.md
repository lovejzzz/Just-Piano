# 单分量极点快速路径（pass150）

2026-10-17。恢复并实现 N=1 的频率/衰减计算，`coupledModes` 不再把单分量一律交给尚不支持它的多项式构造器。独立数值对照通过；**没有取得新单分量声部的原生内部轨迹或独立音轨等价结果**。

## REA 及方程

新的 Ghidra 12.1.4 分析正常 exit0：`FUN_1006d2c10`，证据 ID `ev_35562c2c45e263a57c090801c1379fc80b76acd3a6a76666460e6c7d66e085d4`，私有报告 SHA256 `a790b91869d85e1ac4176c69928c125f73fb0a081242edaad874306cbdf93ac5`。目标仍为既有只读 ARM64 文件。

入口在 `6d2cbc..6d2cc0` 区分分量数；`6d2f50..6d2fb8` 的快速路径直接调用复数除法例程两次，没有构造复多项式或执行 QR。反编译没有正确表达复数返回值的两个寄存器，因此另按 ARM 的 d0/d1 使用顺序核对。

对 N=1，令 `r=1/(p+i*q)`：

```
frequency = float32(FMA64(mode / -π, Im(r), center))
decay     = float32((mode + mode) * Re(r))
```

两个输出再以 double 承载 float32 值，和 JavaScript 中相应数值一致。这个分支不消费 lambda 元素，不使用多分量路径的频率绝对值、排序或共同衰减下界；不能把 N>=2 的后处理套进来。实现只接受正 modal coordinate、有限非零复分母及有限 float32 输出，N=0 继续拒绝。

## 复数倒数及编译器例程核对

新增 `native-complex-reciprocal.mjs`，实现 `9b39e0` 的有限非零分母路径：按最大分母分量提取指数、精确二进制缩放、保留平方/FMA/除法顺序，再缩放实部与虚部。缩放使用位运算及 ties-even subnormal 舍入，保留符号零，不依赖平台复数库或外部进程计算预测。

独立 C 对照程序通过编译器自身的 `__divdc3(1,0,p,q)` 和标量 FMA 生成参考值。本机构建链接入的复数除法代码，从例程起点至 text 末尾共 **1412 字节**，与 Pianoteq 对应范围逐字节一致，SHA256：`cd52f4e2ce43c31c7ceb82e7192255c86d0e70f8955f3e3031afaeb945699f2e`。该程序由正常编译器链接例程，不向目标附加、注入或改写代码。
