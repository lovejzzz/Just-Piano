# pass253：重击硬度与支持模态历史模型接入连续链

新增[历史模型生产器](../dsp/archive-excitation-history.mjs)，复用已有B2100八曲线生产器，并补上历史响应曲线的构造。运行时激励生产器现在自行提供正/负方向增益、重击硬度倍率、普通分支方向、独立调音的回退频率、重击随机幅度、历史随机幅度/上下限/混合量和完整历史曲线。原生对应字段只作比较。

这闭合的是当前普通A4场景的历史**模型输入**，不是整个重击调度、所有琴槌接触/弦反馈或整机已完成。

## 来源与运算顺序

按已校验ARM64列表核对：

| 输出 | 存档来源 | 原生边界 |
| --- | --- | --- |
| positiveGain / negativeGain | B1c8七曲线compound的第5/6项，即B358/B3a8 | 1c7b18..1c7b50 |
| G378..394八个字段 | B2100版本3的八曲线，按音符求值 | 1c64d8..1c6630 |
| repeatScale | 上述G380（B21a0） | 1c6550..6554 |
| 重击randomScale | G394（B2330） | 1c662c..6630 |
| 历史randomScale / upper / lower | G388 / G38c / G390 | 1c65a8..1c6604 |
| 历史混合量 | B2100.scalar2b0，即B23b0 | 1c6740..6744 |
| 历史曲线G398 | B2100.curve_list280，即B2380，按音符混合相邻曲线 | 1c6634..1c6710、5be5fc |
| direction=0 / noteScale=1 | 明确选择普通音符分支 | 35f070..35f078 |

G回退频率取既有独立存档调音；当前源表非空，未新增空源回退分支的实际发声验证。

曲线列表构造使用float32音符间距与除法选择混合比例；端点复制相应成员。内部混合合并两条曲线的X节点，对各成员用缓存倒数插值，再以“旧项先乘并落地、新项FMA”的次序生成Y。没有将普通scalar reader的另一种FMA次序套到这里。输出仍交给原有compactScalarCurve参与支持历史计算。当前实现明确限普通、非空成员曲线。

A4选择60/72两个成员，混合比例.75，自产4节点曲线与原生逐位一致。不同成员X坐标的合并分支有合成单测，**没有直接原生覆盖**，报告differingMemberXCoordinatesVerified=false保留。非普通、空成员及其他尚未实现配置不静默填默认值。

## 同一自产控制传给各消费者

连续链将自产硬度控制传到硬度谱，将自产randomScale、historyControls和historyCurve传到支持模态历史更新，旧声部历史状态沿原有连续计算传递。

另发现pass252生成的混合值尚有三个消费者保留原记录：extraControls.floor/blend及谱referenceBlend。本轮也改为用自产混合值；普通方向同时传给附加谱和支持行选择。

第一次反向测试把原生方向改为1时，支持行选择仍从旧extraControls对象读值，导致向量形状检查拒绝。该失败保留。修复为将同一个自产extraControls对象传到支持模块后，19项目标扰动只产生19项比较差异，音频保持不变。没有放宽支持行或pruning的检查；补充了失败诊断以记录此前实际比较的数量。

## 原生新采集与数值覆盖

[两点只读采集器](../scripts/pianoteq_capture_excitation_history.py)在1c7b54读取配置结果，在35f07c读取**实际经过普通分支**的声部。后一处不只检查方向数值碰巧为0。采集八个模型字段、方向增益、调音频率、完整历史曲线及混合量。[核对器](../scripts/pianoteq_verify_excitation_history.mjs)从当前存档独立生成全部预测。

| 新采集 | 事件音符 | 比较数 | 差异 |
| --- | --- | ---: | ---: |
| 五击A4 | 69 | 194 | 0 |
| 五个音符 | 21、60、69、72、108 | 470 | 0 |

第二次含15条配置记录和5个实际普通分支事件，5个不同声部地址。覆盖历史曲线列表的低端、节点、内部混合及高端。正/负方向增益的活动分支仍未验证。两进程均terminal、exitStatus=0，普通错误及historyErrors为空；沿用采集器的parentSoundboardCaptureComplete=false保留。本批是参数/初始化验证，没有五音符连续PCM等价结论。

## 参数确实参与声音

- 同时改19个原生比较值（含混合值的其他消费者）：完整低位置报告恰19处差异，自算49,152个样本不变。
- 私有解码输入中把重击硬度曲线Y加.01：至epoch1/age576，378,429项检查有12,504处差异；已实际比较20,544个连续样本，其中1,716个不同，随后严格worker pruning检查拒绝。
- 把A4所用两条历史响应成员曲线Y加.1：至epoch3/age14720，3,934,660项检查有1,193,713处差异；已比较252,288个连续样本，其中177,423个不同，随后同样拒绝。

这两项是解码源的因果实验，不是改变实际预设后与新原生音色的完整等价验证。没有完整负例报告，也没有将停止后的样本算入比较。

新五音符原生记录中的随机幅度目标、历史Y目标、方向目标各改单项，分别恰1差异，独立预测不变。合成单测验证节点合并、端点、插值、资产不被修改及无效形状拒绝；它不替代原生和音频验证。
