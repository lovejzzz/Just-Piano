# 延迟环的未写入历史：pass99

新五声部实验中，声部1至4在elapsed=0时的432槽延迟环包含残留值。重放不能把这些值当作声音历史，也不能要求原生分配的内存全零。`3e229c`在elapsed小于length时只写入环，不读取环；达到length后才开始读取，每个槽位此时都已由本声部输入覆盖。

因此独立状态仍以自己的零缓冲建立，不复制原生残留。目标环的比较只覆盖已写入槽：elapsed小于length时比较索引小于elapsed的槽，之后比较完整环。长度、计数器、增益和平滑状态仍逐项核对；初始elapsed必须为0。当前短音频实验没有覆盖32位elapsed回绕。

这修正了pass98过强的“初始原生环全零”限制，并非放宽实际输出的逐位比较。pass98原始捕获本身恰好满足全零条件，其历史通过记录仍有效，但那一轮“修改初始未写入槽应拒绝”的负对照不再是正确的通用条件。

## 验证

同一pass98完整捕获用新规则重放，5727596项零差异，仍直接比较全部2678块、514176个延迟后输出采样。检查数减少7584项，全部对应尚未被原生读取的环槽；输出采样比较数没有减少。
