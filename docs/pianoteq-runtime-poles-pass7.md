## 第四次：复系数的真实数值闭合

针对已定位的回调问题，第四次改用固定内部硬件点 `1006d2ce4`，在 `476298` 已返回后直接读取 `x20=N`、`x22=lambdaVector`、`sp+48=complexCoefficientsVector`，无需动态返回断点。保存的 `v8..v13` 原始 16 字节均由逐字节读取后用 `struct.unpack` 解码，确认先前短小数读数不是寄存器格式化误差。

实际常数为 `kappa=3.141592653589793`、`gamma=0`。本次 N=3 采集的 lambda 与前表相同，p=1021.37、q=−671.371、mode=2。

按第五轮恢复的公式独立生成：

- `mean(lambda)=174.4706666666667`。
- `S=[2.4638622083714067e-5, -1.5099991919794497e-9, -1.6553087366663201e-6]`。
- `T=[2.354369764856811e-8, -7.035740449311744e-13, -4.7443100605299535e-9, -6.601697776369605e-10]`。
- 复系数按低阶生成次序为 `[-2.404682646731801e-5+i*1.580655583401682e-5, 7.186094222721399e-10+i*2.4638149724503947e-5, 4.845695966523478e-6−i*3.186702188840035e-6, 6.742776057850623e-7−i*2.098527580448224e-6]`。

独立 Python 普通 double 乘加重建的 8 个实数中，7 个与内存 double 字节一致。唯一不一致项为系数 1 的实部：预测 `7.186094222713537e-10`，运行值 `7.186094222721399e-10`，绝对误差 `7.862351722316528e-22`，相对误差 `1.0941064058771871e-12`。这是接近相消的项；尚未按 ARM FMA 的全部执行次序重建，不能把误差原因断言为已证明。

对照实验把末因子中的 `beta[N−2]` 改成对称的 `beta[N−1]`，最大绝对误差上升为 `7.304318288852329e-9`。这支持保留第五轮原指令揭示的不对称索引，而不是为数学形式整齐改写公式。

证据为 `capture_fixed.py`、`attempt4-runtime.json`、`verify_coefficients.py`、`coefficient-verification.json`。第四次随后停于另一个线程的系数点和目标线程的 `1006d3280`；输出回调没有完成，不能宣称该次进程正常结束或音频逐字节一致。上节的 PCM 等价性仅属于成功完成的第三次，不属于第四次。
