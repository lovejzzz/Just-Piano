# 端点索引排序与四表组装（pass154）

2026-10-17。实现 `1026dc` 中间混合分支的相同行号配对、频率排序与四表重排。输入仍是显式提供的两个端点四表，**不代表两端点生产、完整缓存生成、原生动态轨迹或真实音轨已通过**。没有接入网页发声。

## REA 和分支核对

本轮 REA 6.5.0 MCP/Ghidra 12.1.4 在单会话只读分析 `1b1fb4`（五项排序）、`2ba584`（partial-sort/堆回退）、`88bfa0`（不完整插入排序），3/3成功，会话exit0。证据 `ev_ca22608c629735092efcb13084eb2f12bb203c9c6f5acbb1df9864800e48f235`。私有 `pass154-endpoint-sort/batch_decompile.json` SHA256 `d5731fdebd2478db3f2ab0b551292486f788a3a46e0a44a5a7314a77014916a2`。

与 pass153 的 `7fd9c4`、`048848` 证据和 ARM listing 联合核对：

- 排序比较 float32 频率值，排序对象是 uint32 行索引。2/3/4/5项小分支、24项插入阈值、128项ninther阈值、默认 `2*floor(log2(n))` 深度。
- 不完整插入最多处理8次搬移。两侧都完成则退出，仅左侧完成则继续右侧且保留原leftmost；不能在该处无条件清除标记。
- 非最左分区可把与前一个pivot相等的值分到左侧并跳过；完整分区之后递归左侧、继续右侧。
- 深度耗尽调用堆排序。建堆在相等键时仍可向下搬移；子节点相等选左。pop采用Floyd下沉和必要的向上修复，相等键次序不能用通用stable sort替代。
- 本地Apple SDK libc++同一类比较器的sort/partial_sort分支结构与上述目标分支一致。只作为独立数值对照，不声称本地编译器产物字节与整个目标排序函数相同。

`dsp/endpoint-frequency-sort.mjs` 实现该索引排序，包含显式诊断深度参数以验证回退；正常调用自算默认深度，不消费原生索引。返回值始终标明 `nativeTrajectoryVerified=false`。

## 初次失败与修正

第一轮6692组、2632417个索引对照出现14067项差异，最早在25项重复频率向量上暴露。私有 `sort-audit.json` 保留 `passed=false`。原因是提前完成左侧分区时误将leftmost置false，导致之后进入不同的相等键分支。按 `7fde14` 之前的原控制流修正，未补索引表或加相等键次序补偿。

完全同一corpus SHA256 `9c346ce67121eab349b9012f3c2ee75c1777c9e80dcf8690451ae5b96779ea0c` 的 `sort-audit-v2.json`：**6692组、2632417个索引全部一致**。含0..140项边界、最长1000项随机有限float、重复值、±0、升降序、organ-pipe；2364组结果确实非stable次序。覆盖13076次ninther、70000次普通分区、7225次相等键分区、7518次不完整插入调用和3148次堆回退。没有削减失败的原比较标准。

## 四表消费

`dsp/endpoint-source-morph.mjs` 消费 row-major `frequency/decay/amplitude/phase` 端点表：

1. blend在float32舍入后为0或1：直接复制所选端点，保留全部行数和原顺序，不执行混合或相位wrap，也不要求未选端点存在。
2. 中间blend：要求列数相同，截到两端最小行数。此调用的option=1，按相同行号配对，不调用一般匹配算法。
3. 对每列分别计算正弦平方频率/衰减、对数幅度、原零幅度类型和相位混合。
4. 从自身混合频率生成索引，同一索引重排四表。列之间不共用排序索引。

这里每列经截断后长度相同，不需要 `048848` 的一般短列填充。没有据此声称一般匹配、独立端点预先补行或完整缓存已恢复；这些上游步骤仍需实现。缓存参考频率/参考行选择与后续归一化也不包含在该四表接口中。

独立 C++ oracle 使用系统sin/logf/expf/pow/fmaf、SDK索引排序及 pass153 的独立ARM相位指令。2000组不同端点行数、1..3列、0/1与中间blend、重复频率和四种零幅度状态，**894636个float32结果逐位一致**，包括截断与复制分支。报告 `source-audit.json` 明确 `nativeEndpointCaptureVerified=false`、`wholeAudioVerified=false`。

新增测试固定独立oracle索引和四表位模式；验证两列不同排列、最小行数、端点直接复制、输入未变、非法布局拒绝，并在禁止Array.sort时通过。纳入 npm test。商业模型/反编译正文/报告和编译产物仍留本机；没有使用Pedalboard，也没有把无关的旧分轨回归计作本轮新音频验证。
