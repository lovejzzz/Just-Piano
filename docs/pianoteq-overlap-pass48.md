# pass48：逆变换归一化与连续重叠历史

[重叠实现](../dsp/convolution-overlap.mjs) 计算固定128点逆变换的64帧输出与下一块历史。令逆变换结果为 `x[128]`，同一输出对象的旧历史为 `h[64]`：

```
out[i] = fma32(x[i], 1/128, h[i])
nextHistory[i] = f32(x[i+64] * (1/128))
```

REA恢复的 `72940c` 先把旧历史复制到当前输出，`70eeb0` 再处理逆变换两半：`454bf8` 用实际SIMD FMLA把前半块加到输出；`65e954` 乘法覆盖后半块历史。内容状态从0或2改为1。这里的比例是当前固定尺寸的1/128，不能推广到未验证的计划。

[连接重放器](../scripts/pianoteq_replay_fft_overlap.mjs) 从记录的逆变换输入频谱自行计算时域数组，再进行归一化和重叠运算。三路历史分别由自己上一块的计算结果携带，首次历史必须为零并与原生核对。没有把观察到的输出或历史反馈给后续计算。输入频谱仍为观察边界，本轮尚未与pass47的乘加窗口合成一次完整采集。

## 数值通过，严格音频审计失败

第三次原生采集完成128块、三路历史，共49152项逐位相同，包括逆变换结果、旧历史、复制后的当前缓冲、最终输出和新历史。进程26073正常exit0，没有触发受限继续。

但完整PCM为已见过的变体 `19481af4235d57e6db522290e2d90dd07fd8cf548c0264f549b1e3863422c84d`：148623个交错样本不同、最大整数差15089、首次差异frame4611、归一化RMS差8.383565726205929e-05。因此本轮严格音频审计保持失败，不能称为正式音频通过。

随后以未调试、未重新签名的官方程序连续渲染三次，同一FXP/MIDI/CLI设置，三次均正常exit0，完整PCM均为官方基准 `1907f854d5c427908038ee9629a5c8997facbb71242e30b94874fc0553a4c9d6`。这三次没有复现差异，但不足以唯一定位调试采集中的音频变体原因；不能据此断言是卷积线程时序或某个具体竞争。

## 不完整运行和检查工具

前两次四硬件点采集均在约95块发生多线程断点停止，没有原生正常退出。第一次留下95块完整配对；仅对复制出的部分重放诊断有48640项相同，原始捕获仍标记不完整，不计正式验证。第二次在固定位置受限继续一次后再次停止；选中线程PC不在允许位置，继续保护没有放行。

第三次移除冗余的逆FFT返回点，保留逆FFT入口、重叠入口/返回三个点：逆FFT计算结果改在重叠入口的同一缓冲核对。没有放宽128块要求或音频判据。原始失败、受限继续记录和数值诊断全部保留。

四个一ULP负对照分别改变旧历史比较目标、当前缓冲比较目标、输出目标和新历史目标，各exit1且恰好一项失败；删除首个逆变换生产记录也立即失败。后一检查证明没有回退使用观察到的逆变换结果。

私有证据包括 `debug-pass48-fft-overlap*`、`pass48-official-controls/`、`pass48-*.json`。REA已导出297条累计证据并关闭保存快照；数量不代表297项算法都已验证。
