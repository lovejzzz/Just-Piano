# 从自算激励和初值到连续声部输出：pass93

本轮将pass92最终初值接入连续递推、能量更新/删模态、频率投影、系数刷新及起音渐入包络。正式D的第一个声部前8块、3个内部模态通道，共1536个float32采样与真实完成缓冲逐位同；连同原有释放/再击链共50173项检查零差异。窗口为512帧、48kHz，约10.7ms，尚未覆盖完整音符或最终立体声。

## 六点同次窗口与时钟

复制点位于20b28c返回后，x23为已经完成的输出矩阵。渲染worker可提前处理多个块，原生模态状态在consumer复制age0时已到worker age512。不能用复制时的实时P/Q去对比age0，也不能从该时刻重置自己的计算。重放在worker的包络完成事件推进自己的模态状态，以consumer age取自己的缓存输出，再比较真实完成矩阵；P/Q通过可靠的刷新点核对。

正式D进程52159正常exit0：5击键、10权重、5初始化、8额外刷新、8完成输出、121释放系数（117活动）、3350连续包络、3295复制。errors、pending、重复包络返回均为0；六点均hardware且最终关闭。保持既有普通Continue策略，无目标代码、数据、寄存器、PC写入或调用注入。

## 连续递推和控制刷新

`dsp/modal-voice-block.mjs`按原次序执行16lane主kernel和8lane尾kernel，清空每组输出后累加各批模态，保留自己的P/Q。调用者提供完整padding状态；八lane尾即使只剩四lane仍读取额外四lane。7c02e8已证明在初始padding中清零P/Q/A/B，重放据此建立自己的这些状态，不从目标取值。

每次刷新由自己的上一块P/Q、R/K/inverse计算能量与删模态，随后按观察的pitch/ratio投影P，更新三角量、自算位置权重、归一化、有效衰减和R/A/B。自算时间步为1/观察采样率，原生时间步仅比较。窗口在age512发生一次真实删除：lane134由末尾lane147补位，自算布局/状态与原生匹配；删除后的下一块音频尚不在本窗口内。

延迟、后处理和组再分配使用既有纯计算模块。本窗口实际delay=0、post processor bypass、spread=1；没有声称本轮覆盖非零延迟、活动滤波或非单位再分配。12lane余数的完整kernel分派仍未恢复，模块明确拒绝该分支。

## 发现并恢复起音包络

C次已有完整同次捕获，8次刷新及模态状态全部匹配，但输出有261项差异，恰为前三通道各前87个采样。后续6块完全一致；保留该失败，没有以音频拟合获得实现。

静态跟进4e285c中的29d444/51b848，确认它生成独立起音包络再乘入每组缓冲。新增`dsp/modal-onset-envelope.mjs`：

- 按7184f0..71858c的float32 FMA顺序混合四个模型值、expression、balance及noteIndex/21。
- 以自算合并源参考行各列频率的float32均值计算duration；本窗口首声部为81采样。
- 原生滤波分支增加6个settle采样，初始remaining=87、delay=0、sine=0、cosine=1、滤波历史=0，均由自己的构造建立并对照原生。
- 每采样执行独立double乘、加、减的正弦/余弦旋转，再转float32；可选平方分支及三系数滤波保持原FMA顺序。尾段强制sine=1，保留cosine；remaining到0后填1且不再推进滤波历史。
- 包络状态跨块携带，乘法使用float32，随后按原流水线处理输出。没有每块从原生包络重播。

double旋转step和三个滤波系数仍在初始点观察，未声明它们已由独立超越函数生成。9a3f0的配置路径已查清：由归一化频率、double tan和双线性系数公式产生滤波系数；该上游尚未接入。本轮duration、初始历史和之后状态/波形独立计算。实际square=false、filtered=true，平方分支尚未运行验证。

D次比较50127项float32、26项double状态和20个随机uint32，共50173项零差异，包含全部1536个完成输出采样。`initialPredictions`保存五个声部真正的初始快照，`finalVoiceStates`另带sampleAge/coefficientAge；声部0在512，其余四个声部仅到0，避免把推进后的状态误称初值。
