# 连续释放与两路激励接入实际声部数组：pass90

本轮从pass89自算合并源继续计算模态筛选和声部数组。A次浮点目标全部吻合但映射时的随机状态检查失败；随后恢复额外随机消费者，B次**23875项检查零差异、passed=true**。A次失败证据保留。没有独立完整WAV或网页声音等价结论。

## 本机log2f

新增`dsp/native-scalar-log2.mjs`，保留macOS 25F80 ARM64系统log2f的65项约减表、4个double系数、double FMA顺序及最终float32舍入。包括正次正规数规格化、零、负数、无穷及NaN语义；不模拟异常标志、errno或NaN payload。

独立C系统oracle与JS核对器测试273907个输入：248901项逐位同、25006项NaN语义同、零差异。覆盖约减边界、指数、次正规数、阈值邻域及固定种子随机输入，非float32全集穷举。旧采集的一个实际阈值返回也逐位同。Math.log2候选在这组数据中没有差异；本轮不将候选吻合作为原生实现恢复的依据。

`selectVoiceModes`默认使用恢复实现，仍允许显式替换数学函数。旧映射重放在存在筛选控制时自行计算索引和布局，不再要求额外log捕获才能计算；可选log只用于对照。旧五个声部共5849项比较零差异，含五个实际阈值对照。

## 同次连续链

新增`pianoteq_capture_release_mapping_chain.py`和`pianoteq_replay_release_mapping_chain.mjs`。保留六个固定硬件点，将pass89的相位末端717cb4换为实际映射末端9517d8；按modal−0x168精确绑定声部，未绑定对象不采集。没有增加硬件点数量。

正式A进程28274正常exit0，5次击键、10次两路权重、5次映射、121次系数（117次活动）、3352连续包络块、3306复制事件；无采集错误、缺块、重复返回或未完成配对。六点最终均确认hardware并关闭。使用既有普通Continue策略，没有目标写入或内部调用注入。

重放使用自己的连续释放、旧release、支持历史、两路随机桥接、谱权重、后处理、合并和相位生成源表。随后用自己的源表及观察的筛选控制计算索引/布局，再以**自己的索引和布局**生成frequency、decay、amplitude、phase、J及referenceDecay。原生索引、布局、声部数组只比较；不反馈。只比较有效lane及原函数实际初始化的四lane尾部，不把未初始化间隙当作零值证据。

总23873项检查中，23853项float32比较全部吻合，20项随机uint32状态比较全部不同。整条报告明确保留失败，不能称为完整状态贯通。

## 新发现的随机状态缺口

本轮检查点比pass89更晚：相位末端之后仍有其它初始化消费者共享voice+2fd0指向的随机状态。不可变指令显示父函数717f18调用6da4b4、717f98循环调用918468，7180d4把同一随机指针传入84141c。这些调用在映射之前，不能假定相位末尾seed就是映射时seed。

诊断搜索发现，从自算相位末尾继续推进xorshift128，五个声部分别在38、40、40、40、38次到达观察状态。**这是定位线索，不是已恢复的调用计划，未把次数硬编码进实现，也未重置到原生目标。** 下一步须根据真实分支、配置和调用顺序自行产生额外推进及对应输出。

REA进一步恢复了6da4b4的float32 FMA拒绝采样和765a30的12个均匀随机数求和；918468每个分量调用后者，84141c还有受配置控制的随机调用。新增`dsp/voice-initial-random.mjs`按观察的配置、启用分支、min(countA,countB)和自己的相位末尾种子计算，未使用搜索得到的次数作为输入。

B次增加早期两路权重事件的来源配置读取，不改变六个硬件点。进程30394正常exit0，3352包络块、3307复制、其余计数同A，无错误、缺块或未完成配对。两路来源快照必须一致。自算拒绝采样尝试数为1/2/2/2/1，加上三个分量各12次推进，实际产生38/40/40/40/38次额外推进；**20个uint32末尾种子全部逐位匹配**。B次23855项float32加20项随机状态检查零差异。生成的随机控制值和微调值尚未直接采集逐值对照，也未连接到自己的噪声/滤波音频；不能将种子一致扩大解释为这些音频分支完整验证。

A次73项扰动仅是失败基准上的诊断。B次另做通过基准上的77项负对照，全部拒绝，包含分量数量、禁用分布、禁用微调、两路来源配置不一致，以及原有源/目标、所有者、逐块计数和完整性对照。例：高档Rattle源改为0会改变合并及映射幅度；单独改动一个映射目标只增加一个差异。历史目标和索引目标没有进入自己的下游计算。
