# 存档琴槌硬度表接入连续声部（pass148）

2026-10-17。把既有 pass13 的存档硬度计算接入当前连续声部，替换琴槌激励插值所消费的两套五节点表与力度节点。实际 30 条分轨仍与历史原生内部音轨逐样本吻合；完整琴槌接触力、弦反作用和制音毡联立方程仍未闭合。

## 替换的输入

`scripts/pianoteq_archive_hardness_source.mjs` 选取基础模型 B 的 11 条曲线及预设 A+9a8 复合字段，调用已恢复的 `archiveHardnessAt69`：Piano/Mezzo/Forte 标量乘音高曲线，按五节点分组乘两套基础表；B+de8 生成五个力度节点。字段摘要与运行条件随私有源报告保存，绑定时重新计算，不以捕获表为生产输入。

源审计新增显式选项：

```
--hardness-source 69 all-zero
```

这要求 decoded base/preset。当前仅接受 note69、All=0、linear-clamp、u=0、hardnessMode=0。两模式、五次击键各比较 primary/secondary 的 knots/values，共 200 个 float32 值。

绑定器必须接受完整 40 条边界记录及零差异，重新生成自身曲线；连续链把这些曲线写入传给 `buildReleaseControlledSpectrum` 的 input。硬度插值与后续谱/支持选择实际使用这些值。已验证分支不消费 edits 曲线，因此没有移植或宣称已验证其它编辑模式。

## 限制

本轮移除了这条已验证分支的硬度节点/表观察依赖，未移除其它硬度控制、注册权重、完整模型及调度输入依赖。仍是历史模型桥接，非新同次模型生成；其它音高、非零 All、随机/编辑硬度分支、完整接触耦合、全部预设与网页声音等价仍未通过。音轨一致不能代替最终立体声验收，不合并、不发布。
