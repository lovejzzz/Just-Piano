- 30ecd4只建立空的主/备用位容器及可选锁，未直接写π、1或其它数学常量。它与参数UI管理器的3ad8对象构造是不同路径。
- 3926b0扫描按逻辑位置读取的64位条目头，以调用键低16位重复掩码后的高48位匹配，低16位给出数据字节数；返回描述符高32位是位数，低32位是条目位置。条目不匹配会跳过64位头及数据，找不到返回0描述符，不会在此生成某个数学默认值。
- 774e04检查所求类型的位数，再把主位容器重新映射到备用容器并交换两者。数据读取保留逻辑位置异或与字节内MSB方向；这类存储重排不会改变应返回的逻辑数值。注册表读取并非对裸double数组的直接加载。
