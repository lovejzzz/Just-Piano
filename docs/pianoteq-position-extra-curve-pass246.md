# 低位置分支的频率曲线（pass246）

为`modalPositionWeights`补齐position<0.125的额外曲线。已完成有效原生预设下的权重验证，并通过默认五击音频回归；低位置的完整音频链仍需新采集验证。

## 计算顺序与存档来源

288f38先计算余弦/指数权重并应用索引截止掩码。若`extraScale=float32_fma(position,-8,1)>0`，仅在每组真实count个模态上追加：

```
weight = float32_fma(extraScale, curveAtFrequency(frequency), weight)
```

该追加在截止掩码之后，可使被掩码的真实模态得到非零追加值；对齐填充不追加。此前未实现此分支。

曲线求值1d17f8以mode=3调用，端点夹取。内部先以float32计算区间宽度和倒数，再用`(frequency-x)*reciprocal`计算t，最后依次计算float32的`t*yNext`和融合乘加`(1-t)*yPrev + t*yNext`。这与直接除法的舍入顺序不同。宽度不大于1e-30时倒数置0。新模块`position-extra-curve.mjs`复现该顺序。

715328..715394把模型B3bd8复制到共享R528；43e0b4..43e0c0再把它复制到V9a8。B3bd8位于存档B2f10的相对cc8。导出器现在包含这第六条基础曲线；源控制模块在低位置强制要求该曲线及已知版本。历史正值来源在不触发额外分支时仍可使用。连续回放的初始化与刷新都传入自身存档曲线，不读取目标权重反推。

## 新原生验证

采集器使用288f38和2890f4两个只读硬件点，配对同线程/同声部的入口与结果，记录布局、模态频率、索引、控制和曲线；没有目标写入或Pedalboard。两个目标均terminal=true、exitStatus=0、回调错误为空、pending=0，原生日志无预设载入错误。

| 有效预设输入 | 实际位置 | 比较 |
| --- | --- | --- |
| A1110=0.0001 | float32(0.001) | 208项零差异 |
| A1110=0.05 | 按存档note69曲线计算的正值 | 208项零差异 |

每次包括192个完整存储权重、14个存档/运行时曲线坐标及2个控制。预测使用自身档案位置、rolloff和曲线；模态频率、referenceFrequency、截止索引与布局仍来自原生入口。不能据此宣称已完成同次独立模型生成。原生生成的WAV为48kHz、双声道24bit且非静音；本轮没有对这两个低位置WAV声称独立引擎逐采样匹配。

只改一个目标权重，恰好一项失败且预测哈希不变；只改存档曲线一个Y，14项失败。单元检查覆盖夹取、区间插值、常量、无效曲线、截止掩码后追加、填充不追加，以及0.125边界。

## 默认音频回归与剩余工作

当前代码对历史五击主链14,230,710项检查零差异。重新生成30条内部float32 WAV后，独立Python解析RIFF，并直接与历史原生audioTail的group/auxiliary数组比较，1,272,576个采样逐字节一致，无归一化、每声部从counter0开始。该场景位置大于等于0.125，所以它验证新改动未破坏默认音频，不证明新增分支的完整音频匹配。

私有证据保留在`pass246-position-{floor,05}-v1/`、两个verification报告、负对照、`pass246-continuous-report.json`和`pass246-stems-audit.json`。商业曲线和原始捕获不提交。当前低位置完整音频、位置事件、释放多项式/rateScale、连续机械耦合、最终立体声、全音区和预设、网页接入仍未完成；不升级completeVoiceVerified/finalStereoAudioVerified，不合并发布。
