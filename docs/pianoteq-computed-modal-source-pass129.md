# 自算极点/权重进入声源四表（pass129）

2026-10-17。本轮连接历史已验证组件，没有新的 Pianoteq 捕获、同次完整声部或完整音频等价结果。

## 计算依赖的变化

新增浏览器兼容的 `constructModalSource`，在 `dsp/modal-source.mjs` 中接收上游频率/原始衰减、谐波权重及显式模型控制，默认用恢复的 nativeDoublePow 计算各行幅度与附加衰减，生成相位、归一化幅度及参考行索引。所有结果从自己的输入生成；不接收原生输出表作为计算种子。

`pianoteq_replay_modal_source.mjs` 新增 `--native-double-pow`、成对的 `--poles-report` / `--weights-report`。桥接模式要求 pass128 已通过且不依赖外部数学的完整极点结果，以及原生 log/exp 生成的权重结果；拒绝缺行、重复行和上下文不匹配。报告保存上游文件 SHA、全部自身预测及明确的历史跨运行标记。

频率和原始衰减来自 pass128 的自身求根输出，权重来自 pass125 的自身谱权重输出。原幅度入口中的 raw_decay/weights 仅作比较。归一化改为读取自身生成幅度，参考行改为读取自身频率；两者不再读取待比较输出矩阵。归一化后没有独立原生观察，仍明确标为未比较。

幅度中所需 double pow 由自身算法生成，再与旧独立系统结果比对；不把旧 result 当预测值。即使某个数学对照项缺失仍能完成全部计算，报告随后以缺比较证据失败；没有为了得到绿色结果忽略缺口。native 模式不调用 Math.pow 作计算或诊断。
