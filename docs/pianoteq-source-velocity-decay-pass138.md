## 来源与运算顺序

使用不可变 ARM64 列表及既有分析，没有新 REA 查询或新原生采集。

* `1c5320` 从 A+c80 与 A+c88 音高曲线生成 G+a0，两项用 float32 相加。
* `714840..71485c` 从 B+168 生成 shared+8c 和 `f(1 / f(20 * log10f(B168)))`；`714754..714758` 将 B+170 存到 shared+30。共享速度模式来自 A+1084。
* `714a98..714b38` 复制 B+1788 力度曲线，并用 `min(f(Ac80/50),1)` 缩放 Y。缩放 helper `5af358` 为逐元素 float32 乘法。
* `57e518..57e53c` 计算力度 helper 的输出 z，再用 `f(1 / FMA(shared30, f(1-f(z+z)),1))` 生成 H+88。hostMode=2另有单位旁路。本轮回放显式选择 hostMode=0。
* `71654c..716578` 把 H+88 传作 `692ffc` 的第一个浮点参数，入口 `693040` 保存为 scratch+10。
* `6942b4..69436c` 将该输入与 params+c0 相乘，再逐元素乘源表衰减；标量和向量均为 float32 乘法。

z 使用既有 `velocityScaleFromControls` 的 nativeScalarLogf/Exp 实现。这里必须取 `helperScale`，即 `57e540` 后可选表达式指数乘法之前的值，不能用最终 H80替代。外层表达式不影响本阶段，计算只消费 helper 输出。
