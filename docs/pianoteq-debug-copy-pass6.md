## 首次取得真实发声的内部数值

将前轮REA静态函数地址 `1008c89ac` 对应到已核对 section 内容一致的调试副本，通过硬件入口/返回断点读取参数与结果。成功运行脚本 `capture_hardness_v3.py` 记录4次调用、无采集错误；不修改节点、寄存器或声音参数。

本次两组曲线使用同一五节点：

```
[0.078125, 0.3515625, 0.5625, 0.7734375, 0.9619140625]
```

内部力度为 `0.7512185573577881`，额外参数u=0，mode=0。两组捕获的原始值为：

```
[.25247254967689514, .4628663659095764, .6979500651359558,
 .9065525531768799, 1.1489561796188354]
[.49652940034866333, .5583528280258179, .6507737636566162,
 .7847131490707397, 1.1181663274765015]
```

真实返回值分别为 `0.884579598903656` 与 `0.7706047296524048`，随后各重复一次。

按原生 `1008c8d44..1008c8d70` 的减法、除法、单精度乘法与融合乘加次序独立计算：

```
t = float32((v-k0)/(k1-k0))
a = float32(1-t)
b = float32(t*y1)
y = fmaf(a,y0,b)
```

4次计算的float32位模式均与实际返回值一致；两种结果分别为小端字节 `cf73623f` 和 `5a46453f`。因此这次对五节点插值完成了输入与输出的真实数值核验，不仅是静态数据流关联。

节点的45/128、72/128、99/128结构可与此前整数力度边界研究对照；本次捕获没有覆盖所有边界力度，不能直接宣称已经验证整个 MIDI→内部力度映射。
