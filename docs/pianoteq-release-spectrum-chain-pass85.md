# 释放与再击控制进入完整对数谱：pass85

本轮把pass84自算硬度继续送入谱控制、附加表及对数谱，不把硬度三个标量当作完整激励。目标仍为本机Pianoteq 9.2.5 ARM64；完整独立声音未完成。

## 同次源计算和实际谱表

[采集器](../scripts/pianoteq_capture_release_spectrum_chain.py)六个固定硬件点保留击键前、源模型初始化、系数、包络返回和声部复制，将硬度站点换为1006950c8对数谱完成处。该处读取同一次调用的源硬度曲线/控制、模型谱表、坐标、附加表来源以及实际谱输出。本轮不再同时观察硬度三个原生标量，不能拼接pass84冒充同时采集。

新增浏览器兼容[buildReleaseControlledSpectrum](../dsp/release-controlled-spectrum.mjs)：以自算repeatFlag/age/attenuation覆盖硬度输入，使用已恢复nativeScalarCos计算硬度，生成谱控制、附加表并用自己的附加表生成logSpectrum。函数只接收源表和源控制，不读原生目标。[重放器](../scripts/pianoteq_replay_release_spectrum_chain.mjs)实际使用此模块；原生谱控制、extraTable和logSpectrum仅作比较，不回填。

同次正式A进程98162正常exit0，六点均hardware且最终关闭，errors为空、逐块counter连续、重复返回0：

| 内容 | 数量 |
| --- | ---: |
| 击键 / 源模型初始化 | 5 / 5 |
| 系数 / 活动系数 | 120 / 116 |
| 系数处全局x变化 | 11 |
| 连续包络块 / 声部复制 | 3351 / 3309 |
| 自算旧release读取 | 4 |
| 谱调用 | 10，每声部mode0/1 |
| 每次谱行数 | mode0为26，mode1为10，共180行 |

**22206项float32比较零差异**，包含180行附加表、180行完整对数谱和40项谱控制。逐块counter、模式/所有权、repeatFlag等结构检查另计，不将不同窗口的比较数相加。

R全局值仍在系数处观察，与绑定声部/模态字段比较；本轮没有pass83的逐次update站点。源配置/选中衰减行、硬度曲线、基础表/坐标/附加表源和其它谱控制仍观察。10次history附加控制均为0，slopeBlend均在0/1已支持分支；非零history所需gain及非平凡幂函数分支没有覆盖。

## 差异确实传到谱输出

45项负对照均先通过原始基准，再逐项拒绝：

- 源初始化时长、多项式尾、采样率和高档Rattle源变化，均传到后续2次slope、2次baseScale和**34个logSpectrum值**。不是只比较源字段或单个函数返回。
- 改变硬度曲线产生29差异；改变基础谱源产生26差异；改变附加源表/控制产生52差异。
- 改变原生谱控制目标、extraTable目标或首/尾logSpectrum目标，分别只产生1处差异；目标未进入自己的下游计算。
- 缺失初始化/包络/复制/谱调用、模式重复、错误所有者/epoch、counter和行数不符、不完整窗口均拒绝。

既有单次初始globalX扰动仍只影响局部控制，未传到本窗口谱终端；保留有限敏感性，不宣称每次扰动必然可见。

## 实际音频：仍不一致

正常官方CLI，沿用官方保存的Rattle分配FXP与普通五次重击MIDI，没有Pedalboard。正式A完整148224帧、双声道24-bit/48kHz，与原版参考有135965个交错样本不同，最大整数差145、首差frame13036，归一化RMS差7.302935098966818e-7。PCM SHA256为1bb79ad0e76ae8fbd916e8fb3580c62196107a2e0bbd86b8352172d2cb6a30b6。

完整PCM严格失败，不因系数/谱表通过而放宽标准；音频仍由原生引擎生成，不是新模块的独立WAV。此次最大差比pass84大，不将它解释为数值误差缩小或声音更接近。
